AI 뉴스가 흩어져 있어 특정 회사의 움직임을 파악하기 어려운 불편을 덜어 줍니다. OpenAI, Anthropic, Google, Mistral, xAI, Meta 6개 기업의 최근 7일 데이터를 모델, 레포지토리, 뉴스 세 가지 관점으로 가중 계산해 신호등 매트릭스로 보여줍니다. 어떤 기업이 가장 활발한지 한 화면에서 비교할 수 있어 AI 제품·투자·취업 준비에 유용합니다.

쓰는 법

  1. 화면 상단의 '데이터 기준 시각'이 채워지면 준비 완료임을 확인합니다.
  2. 신호등 매트릭스를 통해 6개 기업의 최근 7일 활동 수준(초록/주황/빨강)을 확인합니다.
  3. '예시로 해 보기' 버튼을 눌러 Mistral과 Anthropic을 비교하거나, 상단 선택 박스에서 원하는 기업을 직접 지정합니다.
  4. 각 기업 카드를 클릭해 급상승 모델, 신규 저장소, 기술 소식 목록을 상세히 검토합니다.
  5. 필요 시 '전체 초기화'를 눌러 6개 기업 전체 보기로 복귀합니다.

자주 묻는 질문

이 앱은 어떤 데이터를 기반으로 속도를 계산하나요?

기술 레이더(246건), Hugging Face 트렌딩(100건), GitHub 신규 저장소(50건), Hacker News 1면(30건) 데이터를 읽어와 모델 3배, 레포 2배, 뉴스 1배의 가중치를 적용해 계산합니다.

AI 기업 순위는 어떻게 결정되나요?

단순 뉴스 건수가 아니라, 모델 출시, 코드 저장소 생성, 기술 소식의 가중치를 합산한 '7일 관찰창' 속도를 기준으로 신호등 색상을 매겨 상대적으로 빠른 순위를 보여줍니다.

실시간 최신 뉴스가 자동으로 갱신되나요?

아니요, 현재는 같은 폴더의 JSON 파일 데이터를 시작 시점에 읽어와 계산합니다. 실시간 크롤링 기능이 아직 구현되지 않았으며, 데이터 파일이 업데이트되어야 최신 정보를 볼 수 있습니다.

휴대폰에서도 표가 잘 보이나요?

네, 최신 버전(v2)에서는 표 열이 잘리지 않도록 최적화되어 있어 모바일에서도 6개 기업 전체를 한눈에 비교할 수 있습니다.
