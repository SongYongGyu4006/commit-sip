AI도구 기능 비교 매트릭스

AI도구 기능 비교가 어려운 CTO를 위한 앱입니다. 기능별 점수를 입력해 레이더 차트로 AI 도구 비교를 시각화하고, 인기 모델 프리셋으로 llm 벤치마크 비교를 시작하세요.

인공지능 기능 비교 매트릭스 바로 써 보기 →

다양한 AI 도구의 기능 차이를 정량적으로 비교하기 어려워 도입을 망설이는 CTO를 위해 만들었습니다. 기능별 점수를 입력하면 레이더 차트로 차이를 직관적으로 보여주고, 비교 결과를 JSON으로 내보내어 의사결정을 지원합니다.

쓰는 법

  1. 인기 모델 프리셋(제미나이 프로, GPT-5 등)을 선택하거나 로컬 모델 이름을 직접 입력해 도구를 등록합니다.
  2. 각 도구의 기능별 점수(0~100)를 입력 칸에 채웁니다.
  3. [비교하기] 버튼을 눌러 레이더 차트와 비교 요약을 확인합니다.
  4. [내보내기] 버튼을 눌러 comparison.json 파일을 다운로드합니다.

자주 묻는 질문

이 앱은 어떤 사람에게 유용한가요?

AI 도구 도입을 결정해야 하는 CTO나 개발 리더에게 유용합니다. 정성적인 설명보다 정량적인 기능 차이를 시각적으로 확인하고 싶을 때 적합합니다.

어떤 AI 모델을 비교할 수 있나요?

제미나이 프로, GPT-5, 클로드 프로, 제미나이 플래시 등 인기 모델 프리셋을 제공하며, 로컬이나 자체 모델 이름도 직접 입력해 추가할 수 있습니다.

비교 결과는 어떻게 저장하나요?

비교 결과를 줄바꿈된 JSON 형식으로 화면에 표시하며, [내보내기] 버튼을 통해 comparison.json 파일로 내려받을 수 있습니다.

외부 인터넷 연결이 필요한가요?

아니요. 외부 네트워크나 CDN 없이 로컬에서 완전히 동작하므로 보안이 중요한 환경에서도 안전하게 사용할 수 있습니다.
