로컬 llm 구축을 고민하는 한국 개발자와 엔추어는 내 pc 사양이 모델 실행에 충분한지 매번 계산해야 하는 불편이 있습니다. 이 앱은 RAM 용량과 양자화 수준을 설정하면 Hugging Face 인기 텍스트 모델 100개 중 내 기기에 맞는 로컬 llm 모델 추천 목록을 즉시 보여 줍니다. 복잡한 손계산 없이 내 PC에서 실행 가능한 모델을 바로 확인하세요.

쓰는 법

  1. 앱을 열고 '예시로 해 보기' 버튼을 눌러 16GB RAM 기준 예시를 확인합니다.
  2. 내 PC 설정에서 RAM, CPU, GPU, VRAM, 양자화, 작업을 선택합니다.
  3. 설정을 변경하면 모델 목록이 즉시 갱신되어 적합 여부를 확인합니다.
  4. 모델 목록에서 '전체 보기'를 눌러 100개 모델 전체를 확장 확인합니다.

자주 묻는 질문

이 앱은 어떤 기준으로 로컬 llm 모델 추천을 하나요?

Hugging Face 인기 텍스트 모델 100개의 파라미터를 4bit 또는 8bit로 양자화했을 때 필요한 메모리를 계산하여, 사용자가 입력한 내 pc 사양(RAM)과 비교해 추정 적합 여부를 판단합니다.

GPU나 VRAM 설정은 어떻게 반영되나요?

GPU를 선택하면 VRAM 기준 배지가 반영되며, Apple 실리콘인 경우 통합 메모리 사용 안내가 표시됩니다. CPU 아키텍처는 추정에 영향을 주지 않아 참고용으로만 표시됩니다.

모든 모델이 정확히 실행 가능한가요?

아니요, 이는 '추정 적합' 기준입니다. 경계 사례 1개에서 별도 구현과 결과가 달라질 수 있으므로 최종 실행 전 직접 확인이 필요합니다.

데이터는 얼마나 자주 갱신되나요?

모델 데이터는 매일 갱신되며, 화면 상단과 하단에 데이터 기준 시각과 이용 조건이 표시됩니다.
