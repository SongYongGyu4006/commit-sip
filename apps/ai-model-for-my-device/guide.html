로컬 llm 구축을 위해 PC 사양을 조사하는 개발자·엔추어의 '파라미터×비트수÷8' 손계산 부담을 덜어 줍니다. 내 pc 사양(RAM)을 한 번만 선택하면 그 기기에 실행 가능한 모델을 즉시 보여 줍니다. Hugging Face 모델 데이터를 기반으로 한 한국어 대시보드입니다.

쓰는 법

  1. RAM(8/16/32/64/128GB), 작업, 양자화 옵션을 선택합니다.
  2. [적용] 버튼을 눌러 결과를 계산합니다.
  3. 가능/불가 개수와 RAM 부족 원인 분해를 확인합니다.
  4. 모델 ID를 클릭해 Hugging Face 페이지로 이동하거나 상세 산출 내역을 봅니다.

자주 묻는 질문

이 앱은 실제 실행 엔진의 측정치인가요?

아니요. 총 필요 메모리는 가중치, 런타임 예약(2GB), KV 캐시를 기반으로 한 이상적인 추정치일 뿐 실제 실행 엔진의 측정치는 아닙니다.

RAM이 부족하거나 파라미터가 미상인 모델은 어떻게 표시되나요?

해당 모델은 흐리게 표시되며, 클릭하면 상세 산출 내역을 볼 수 있습니다. 상단에서는 'RAM 부족' 또는 '파라미터 미상' 원인 분해와 전체 카운트를 확인할 수 있습니다.

GPU나 VRAM도 고려하나요?

RAM 선택에 GPU·VRAM·CPU 아키텍처를 더했고, 모델별로 'VRAM 전량 적재' 또는 'RAM 오프로딩 필요(추정)' 보조 배지를 표시합니다. 다만 실행 가능 판정은 기존 RAM 기준 그대로 유지됩니다.

모델 목록은 얼마나 자주 갱신되나요?

모델 데이터(data/hf_models.json)는 매일 갱신됩니다.
