내 기기에 맞는 AI 모델 찾기

PC 메모리만 선택하면 Hugging Face 인기 모델 100개 중 내 사양에서 실행 가능한 로컬 llm 추천 목록을 즉시 알려주는 한국어 대시보드입니다.

내 기기에 맞는 AI 모델 찾기 바로 써 보기 →

자기 PC에서 로컬 LLM을 돌려보려 PC 사양을 조사하는 한국 개발자·엔추어의 불편을 덜어 줍니다. '파라미터×비트수÷8'을 매번 손계산해야 하는 번거로움을 없애고, RAM 용량만 입력하면 해당 기기에 실행 가능한 모델 목록을 바로 확인하게 합니다.

쓰는 법

  1. 앱을 열고 '예시로 해 보기' 버튼을 눌러 16GB 메모리 예시로 채웁니다
  2. 본인 PC의 RAM 용량(8~128GB)을 선택합니다
  3. 원하는 양자화 수준(8bit/4bit)을 선택합니다
  4. 필요 시 GPU/VRAM 설정을 조정하여 메모리 배치 안내를 확인합니다
  5. 화면 상단의 '돌릴 수 있는 모델 수'와 상위 3개 목록을 확인합니다

자주 묻는 질문

이 도구는 어떤 사람에게 유용한가요?

자기 PC에서 로컬 LLM을 돌려보려 PC 사양을 조사하는 한국 개발자나 엔추어스트에게 유용합니다.

GPU나 VRAM 설정은 어떻게 반영되나요?

GPU와 VRAM을 선택하면 모델 카드에 메모리 배치 안내가 실제로 반영됩니다. Apple 실리콘을 선택하면 통합 메모리 사용 안내가 뜨고, GPU가 없으면 VRAM 선택은 비활성화됩니다.

RAM이 부족하거나 파라미터가 미상인 모델은 어떻게 표시되나요?

RAM이 부족하거나 파라미터 정보가 없는 모델은 흐리게 표시됩니다. 해당 모델을 클릭하면 총 필요 메모리 산출 내역을 자세히 볼 수 있습니다.

모델 데이터는 얼마나 자주 갱신되나요?

모델 데이터는 매일 갱신되며, 화면 하단에 데이터 기준 시각과 이용 조건이 표시됩니다.

경계 사례에서 결과가 다를 수 있나요?

네, 경계 사례 1개에서 별도 구현과 결과가 달라질 수 있으므로 최종 실행 전 확인이 필요합니다.
