AI 모델 시장 판: 로컬 실행과 API 비용 비교

내 RAM과 양자 설정으로 로컬 llm 실행 가능 여부를 즉시 확인하고, Hugging Face 인기 모델과 OpenRouter API 가격을 한눈에 비교하세요.

AI 모델 시장 판 바로 써 보기 →

로컬 llm 구축을 고민하는 개발자와 학생의 불편을 덜어 드립니다. 내 장비 사양으로 돌릴 수 있는지, 아니면 클라우드 API로 쓰면 얼마인지 흩어진 정보를 한 표로 정리해 줍니다.

쓰는 법

  1. 내 PC의 RAM(GB)과 양자(4/8/16비트)를 설정합니다.
  2. 화면 상단의 '로컬 실행 가능' 모델 목록과 메모리 요구량을 확인합니다.
  3. 관심 있는 모델 3개를 ☆로 선택해 로컬 메모리와 API 가격을 나란히 비교합니다.
  4. 가격과 컨텍스트 길이를 고려한 그래프를 통해 최적의 모델을 선택합니다.

자주 묻는 질문

이 앱은 어떤 데이터를 사용하나요?

매일 갱신되는 Hugging Face 인기 모델 데이터와 OpenRouter의 API 가격 정보를 모델 계열별로 짝지어 제공합니다.

로컬 LLM 실행 가능 여부를 어떻게 판단하나요?

사용자가 입력한 RAM 용량과 선택한 양자 비트 수(4/8/16)를 기준으로 모델 실행에 필요한 메모리를 계산하여 가능 여부를 색상으로 표시합니다.

API 가격과 로컬 실행을 어떻게 비교하나요?

모델 3개까지 즐겨찾기(☆)로 선택하면, 로컬 실행에 필요한 메모리와 API 사용 시 토큰당 가격을 나란히 보여주는 비교 표가 열립니다.

데이터가 최신이 아닌 경우 어떻게 되나요?

데이터 파일 로딩에 실패하면 화면에 '불러올 수 없음' 안내를 표시하며, 이전 데이터로 인한 오해가 없도록 처리합니다.
