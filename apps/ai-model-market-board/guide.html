AI 모델 시장 판: 로컬 실행과 클라우드 비용 비교

Hugging Face 인기 모델과 OpenRouter API 가격을 한 표로 보여 줍니다. 내 RAM과 양자를 설정해 로컬 llm 구축 가능 여부를 즉시 확인하세요.

로컬 LLM 구축 시 내 컴퓨터 사양이 충분한지, 아니면 클라우드 API를 쓰는 게 더 경제적인지 고민하는 개발자와 학생을 위한 도구입니다. 흩어져 있는 모델 정보를 한 표로 정리해 선택의 부담을 덜어 줍니다.

쓰는 법

  1. RAM(GB)과 양자(4/8/16비트) 옵션을 내 장비 사양에 맞게 설정합니다.
  2. Hugging Face 인기 모델과 OpenRouter API 가격이 매칭된 표를 확인합니다.
  3. 색상 코드로 표시된 '로컬 가능' 여부를 통해 실행 가능 모델을 선별합니다.
  4. 관심 있는 모델 3개까지 즐겨찾기로 등록해 세부 스펙을 나란히 비교합니다.

자주 묻는 질문

로컬 llm 사양이 부족하면 어떻게 알 수 있나요?

앱 상단의 RAM과 양자 옵션을 내 컴퓨터 사양으로 설정하면, 각 모델별 필요한 메모리 용량과 실행 가능 여부(초록/빨강)가 즉시 계산되어 표시됩니다.

llm api 비용은 어떻게 비교하나요?

OpenRouter의 최신 API 가격 데이터를 모델 계열별로 짝지어 표에 표시하므로, 로컬 실행과 클라우드 사용 비용을 직접 비교할 수 있습니다.

데이터는 실시간으로 갱신되나요?

네, Hugging Face와 OpenRouter 데이터를 매일 갱신하여 최신 인기 모델과 가격을 반영합니다. '새로고침' 버튼을 누르면 최신 데이터를 불러올 수 있습니다.

휴대폰에서도 사용할 수 있나요?

네, 모바일 화면(390px)에서도 표가 겹치지 않도록 최적화되어 있으며, 가로 스크롤을 통해 전체 모델 목록을 확인할 수 있습니다.
