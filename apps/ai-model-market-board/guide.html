AI 모델 시장 판: 로컬 LLM 실행 및 API 가격 비교

Hugging Face 인기 모델과 OpenRouter API 가격을 한 표로 보여 줍니다. 내 RAM과 양자를 입력해 로컬 llm 구축 가능 여부를 즉시 확인하세요.

로컬 llm 구축 시 내 장비 사양이 부족한지, 아니면 클라우드 API로 전환해야 하는지 고민하는 개발자와 학생을 위한 도구입니다. 흩어져 있는 모델 인기도와 API 가격을 모델 계열로 짝지어 한 표로 보여 줍니다. 내 RAM(GB)과 양자(4/8/16비트)만 입력하면 로컬 실행에 필요한 메모리와 가능 여부를 즉시 알려 줍니다.

쓰는 법

  1. 앱을 열고 '예시로 해 보기' 버튼을 눌러 기본 데이터를 불러옵니다.
  2. 내 장비의 RAM(GB)과 양자(4/8/16비트) 옵션을 선택합니다.
  3. 모델 목록에서 '로컬 가능' 셀의 색상(초록/빨강/회색)으로 실행 가능 여부를 확인합니다.
  4. 관심 있는 모델의 '가족' 셀을 클릭해 최대 3개까지 즐겨찾기를 추가합니다.
  5. 아래 비교 표와 그래프에서 메모리, API 가격, 컨텍스트 길이를 나란히 비교합니다.

자주 묻는 질문

이 앱은 어떤 데이터를 사용하나요?

매일 갱신되는 Hugging Face 인기 모델 데이터와 OpenRouter API 가격 데이터를 로컬 JSON 파일로 읽어 와서 사용합니다.

로컬 실행 가능 여부는 어떻게 계산하나요?

사용자가 입력한 RAM 용량과 선택한 양자화 비트(4/8/16)를 기반으로 모델이 요구하는 메모리 크기를 계산하여 가능 여부를 표시합니다.

모든 LLM 모델의 실시간 가격을 정확히 반영하나요?

OpenRouter의 공개된 API 가격 데이터를 기반으로 하며, 매일 갱신되는 데이터를 사용하지만 모든 비공개 모델이나 변동이 잦은 특수 요금제는 반영되지 않을 수 있습니다.

그래프에서 가로축과 세로축은 무엇을 의미하나요?

가로축은 모델이 한 번에 처리할 수 있는 컨텍스트 길이(글자 수)를, 세로축은 해당 모델의 API 가격을 나타냅니다.
