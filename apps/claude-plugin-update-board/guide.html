Claude 플러그인 업데이트 보드

GitHub에서 최근 7일 내 새로 뜬 claude 플러그인 관련 저장소를 골라, 최근 3일 내 업데이트 여부와 별 수를 한 표로 비교해 보여 줍니다. AI 개발자의 트렌드 파악을 돕습니다.

Claude 플러그인 업데이트 보드 바로 써 보기 →

AI 개발자가 Claude Code 플러그인 변경 사항을 파악하기 어려운 불편을 덜어 줍니다. GitHub에서 최근 7일 내 새로 뜬 저장소 중 이름·설명에 Claude가 언급되는 항목을 자동으로 선별합니다. 최근 3일 내 업데이트 여부와 별 수를 한 표로 비교해 최신 트렌드를 쉽게 파악할 수 있습니다.

쓰는 법

  1. 화면 맨 위의 이번 주 신규 Claude 저장소 수와 상위 항목을 확인합니다.
  2. 각 행의 순위, 저장소 이름, 설명, 별 수, 상태(신규·갱신·가라앉은)를 표로 확인합니다.
  3. 상태 필터(전체, 신규, 갱신, 가라앉은)를 선택해 관심 있는 저장소만 걸러 봅니다.
  4. 「예시로 해 보기」를 눌러 예시 데이터로 기능을 테스트하거나 「실제 데이터로 새로 계산」으로 최신 데이터로 전환합니다.
  5. 저장소 이름을 클릭해 GitHub 원본 페이지로 이동합니다.

자주 묻는 질문

이 앱은 어떤 데이터를 기반으로 작동하나요?

GitHub에서 최근 7일 내 새로 생성된 저장소 중 이름이나 설명에 'Claude'가 언급되는 항목을 추출합니다. 이후 최근 3일 내 업데이트 여부와 별 수를 기준으로 상태를 분류합니다.

상태(신규, 갱신, 가라앉은)의 기준은 무엇인가요?

신규는 최근 7일 내 새로 뜬 저장소, 갱신은 최근 3일 내 업데이트가 있는 저장소, 가라앉은은 3일 넘게 업데이트가 없는 저장소를 의미합니다.

실제 데이터를 불러오지 못하면 어떻게 되나요?

네트워크 요청으로 실제 데이터를 읽지 못할 경우, 자동으로 예시 데이터(3개 저장소) 보드로 전환되어 기능을 계속 체험할 수 있습니다.

휴대폰에서도 표를 볼 수 있나요?

네, 390px 이하의 작은 화면에서는 표가 가로로 넘치지 않도록 카드형 행(이름, 설명, 별·상태)으로 자동 변환됩니다.
