제출 서류 팩키지 만들기

제출 서류를 pdf 서류 합치기 기능으로 하나로 묶고, pdf 주민번호 가리기로 개인정보를 안전하게 처리합니다. 브라우저에서 바로 작동하는 무료 앱입니다.

제출 서류 팩키지 만들기 바로 써 보기 →

취준생, 직장인, 학부모가 제출 서류를 하나로 묶을 때 개인정보 유출 걱정과 번거로운 설치 없이 해결합니다. 파일을 끌어다 놓기만 하면 기기 안에서 합치고 주민번호를 가려 안전한 PDF를 생성합니다.

쓰는 법

  1. PDF, JPG, PNG 형식의 제출 서류 파일을 앱에 끌어다 놓습니다.
  2. 전세대출, 취업, 학교 등 용도에 맞는 순서와 목표 용량을 설정합니다.
  3. PDF 텍스트나 이미지에서 발견된 주민번호 위치를 확인하고 검게 가립니다.
  4. 목표 용량에 맞춰 압축된 package.pdf 파일을 내려받습니다.

자주 묻는 질문

제출 서류를 올리는 것이 안전합니까?

네, 모든 처리는 브라우저 안에서만 일어나며 파일을 외부 서버로 전송하지 않습니다.

주민번호 가리기는 어떻게 작동하나요?

PDF는 텍스트에서 자동으로 찾은 번호를, 사진이나 스캔본은 사용자가 직접 박스를 그려 가립니다.

인터넷 연결이 필요한가요?

아니요, 네트워크나 외부 서버 없이 브라우저로 앱을 여는 것만으로 사용할 수 있습니다.

만든 파일은 어디에 저장되나요?

완성된 package.pdf는 내려받아 저장하며, 설정값은 현재 브라우저에 임시로 보관됩니다.
