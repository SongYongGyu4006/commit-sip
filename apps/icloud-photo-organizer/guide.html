아이클라우드 사진 용량 정리 및 라이브포토 최적화 도구

아이클라우드 사진 정리 시 라이브포토 영상과 사본 용량을 자동 분석합니다. 버릴 항목을 체크하면 촬영일 폴더 구조를 미리 확인하고, heicpack-state.json으로 상태를 저장할 수 있습니다.

아이클라우드 사진 용량 정리 바로 써 보기 →

아이클라우드에서 내려받은 사진 묶음에서 라이브포토 영상, 사본, 편집 전 원본이 차지하는 용량을 정확히 파악해야 하는 분을 위한 도구입니다. 각 범주의 용량을 시각적으로 보여주고, 삭제할 항목을 선택하면 최종 폴더 구조를 미리 확인시켜 줍니다. 모든 계산은 기기 내에서 이루어지며, 사진 파일 자체는 수정하거나 삭제하지 않습니다.

쓰는 법

  1. 첫 화면의 '예시로 해 보기' 버튼을 눌러 실제와 동일한 흐름으로 결과를 미리 확인합니다.
  2. '범주별 용량' 목록에서 라이브포토 영상, 사본, 편집 전 원본 중 버릴 항목을 체크합니다.
  3. '사진을 여기에 올리세요' 칸에서 아이클라우드에서 내려받은 폴더를 선택합니다.
  4. '폴더 미리보기' 화면에서 촬영일 기준 폴더별 장수와 용량을 확인합니다.
  5. '데이터 관리'에서 현재 상태를 heicpack-state.json 파일로 내보내어 저장합니다.

자주 묻는 질문

이 앱은 사진 파일을 직접 삭제하거나 변환하나요?

아니요. 이 앱은 파일 목록과 메타데이터를 분석하여 용량과 폴더 구조를 '미리보기'만 제공합니다. 사진 파일 자체를 삭제하거나 형식을 변환하는 기능은 없으며, 모든 계산은 브라우저 안에서만 수행됩니다.

라이브포토 용량 줄이기에 도움이 되나요?

네, 라이브포토에 포함된 영상 파일(.MOV)과 사진 파일(.HEIC)의 용량을 각각 분리하여 보여줍니다. 영상 파일을 버리기로 선택하면 최종 용량이 얼마나 줄어드는지 실시간으로 확인할 수 있어 라이브포토 용량 관리에 유용합니다.

Photos Details.csv 파일이 없으면 어떻게 되나요?

아이클라우드 웹에서 내보내기 시 함께 오는 Photos Details.csv 파일이 없으면, 촬영일 기반 폴더 분류가 불가능하여 모든 파일이 '날짜 없음' 폴더로 묶여 표시됩니다. 정확한 폴더 구조를 보려면 CSV 파일이 포함된 폴더를 선택해야 합니다.

내 사진 데이터가 서버로 전송되나요?

전혀 아닙니다. 파일은 브라우저 안에서만 계산되며, 사진 바이트는 외부로 전송되지 않습니다. 상태는 브라우저의 localStorage에 저장되며, 필요 시 JSON 파일로 내보내거나 가져올 수 있습니다.
