대부분의 시세 앱은 달러 기준이라 환율 변동이 수익에 미치는 영향을 놓치기 쉽습니다. 이 대시보드는 원화 가격과 환율 효과를 명확히 구분해 보여 줍니다. 한국 개인 투자자가 실제 원화 계좌 기준으로 자산을 관리할 수 있도록 돕습니다.

쓰는 법

  1. 대시보드 화면에서 비트코인·이더리움의 원화 가격과 환율 효과를 확인합니다.
  2. 코인 선택 메뉴에서 필요 시 솔라나를 추가합니다.
  3. 백업 메뉴에서 선택 사항을 krcoinfx.json 파일로 내보내거나 가져옵니다.
  4. 예시로 해 보기 버튼을 눌러 내장 데이터로 기능을 테스트합니다.

자주 묻는 질문

도지코인이나 테더도 볼 수 있나요?

아니요, 현재는 비트코인, 이더리움, 그리고 선택적으로 솔라나만 지원합니다.

코인 원화 시세는 실시간으로 갱신되나요?

시세와 환율 데이터는 data 폴더의 파일 기반으로 표시되며, 실시간 외부 API 연동은 하지 않습니다.

내 선택한 코인 목록은 어떻게 저장되나요?

브라우저의 localStorage에 저장되어 새로고침해도 유지되며, JSON 파일로 백업할 수도 있습니다.

차트 기능이 있나요?

차트 없이 숫자와 막대 그래프로만 표시하며, 외부 네트워크나 CDN을 사용하지 않습니다.
