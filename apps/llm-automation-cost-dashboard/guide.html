LLM 작업 자동화 비용 대시보드

OpenRouter와 Hugging Face 데이터로 코딩·테스트 등 LLM 작업 1회당 비용을 계산합니다. llm api 비용 비교와 4주 전 대비 변화를 추적해 비용 최적화에 도움을 줍니다.

LLM 작업 자동화 비용 대시보드 바로 써 보기 →

LLM이 특정 기술 영역을 빠르게 대체하면서 지속 가능한 경쟁 우위를 파악하기 어려운 소프트웨어 엔지니어를 위해 만들었습니다. OpenRouter 모델 가격과 Hugging Face 신규 모델 데이터를 기반으로 코딩, 테스트, 문서화, 운영 작업 1회당 가장 싼 자동화 비용을 계산해 드립니다. 4주 전 대비 비용 변화를 명확히 보여주고 날짜별 기록을 브라우저에 저장하여 추이를 쉽게 추적할 수 있습니다.

쓰는 법

  1. 앱을 열고 '예시로 해 보기' 버튼을 눌러 내장 샘플로 결과를 확인합니다.
  2. 작업군별(코딩·테스트·문서화·운영) 최저 모델과 1회당 달러 비용을 확인합니다.
  3. 4주 전 대비 비용 변화율(싸짐/비싸짐/변화 없음)을 확인합니다.
  4. 최근 7일 신규·인기 모델 요약을 살펴봅니다.
  5. 기준 설정에서 최소 컨텍스트 길이를 변경하거나 기록을 내보내기/가져오기합니다.

자주 묻는 질문

이 대시보드는 어떤 데이터를 사용하나요?

OpenRouter의 모델 가격 데이터와 Hugging Face의 신규 모델 데이터를 사용합니다. 시작 시 data/ 폴더의 공개 파일을 읽어와 계산합니다.

실제 API 키나 파일 없이도 사용 가능한가요?

네, '예시로 해 보기' 버튼을 누르면 실제 파일을 읽지 않고 내장된 샘플 데이터로 결과를 바로 보여주고 기록합니다.

비용은 어떻게 표시되나요?

작업 1회당 달러 단위로만 표시하여 금액을 그대로 비교하고 읽을 수 있도록 했습니다. '100만 토큰 환산'처럼 규모가 크게 보이는 표기는 사용하지 않습니다.

변화율이 0%로 표시되는 이유는 무엇인가요?

4주 전 비교 자료 없거나 가격이 동일할 경우 '변화 없음' 또는 '비교 자료 없음'으로 명확히 표시하며, 실제 변동 시에는 ±%로 표시합니다.
