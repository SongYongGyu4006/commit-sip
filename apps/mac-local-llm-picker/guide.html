맥 로컬 LLM 고르기

맥 로컬 ai 모델을 고를 때, Mac Studio M5 Max 48GB 실측 데이터로 내 맥 메모리에 들어가는 모델만 골라 용도별 순위를 보여 줍니다. 두 모델을 나란히 비교하고 JSON으로 저장할 수 있습니다.

맥 로컬 LLM 고르기 바로 써 보기 →

자기 맥에서 로컬 AI를 돌리려 해도 어떤 모델이 내 메모리에 들어가는지, 실제로 얼마나 빠른지 모릅니다. 이 앱은 Mac Studio M5 Max 48GB에서 직접 측정한 실측 데이터를 기반으로, 내 맥 사양에 맞는 모델만 골라 용도별 순위를 보여 줍니다. 커뮤니티 추측이 아닌 숫자로 모델 선택의 부담을 덜어 줍니다.

쓰는 법

  1. 상단에서 내 맥 메모리 용량(예: 16GB)과 용도(한국어·코딩·도구·속도)를 선택합니다.
  2. 내 메모리에 들어가는 모델만 필터링되어 용도별 순위로 정렬된 목록을 확인합니다.
  3. '두 모델 비교' 탭에서 관심 있는 두 모델을 선택해 실측 수치와 차이를 나란히 봅니다.
  4. 관심 모델 옆의 [저장] 버튼을 눌러 모델을 브라우저에 저장합니다.
  5. '관심 모델' 탭에서 [내보내기]를 눌러 JSON 파일로 저장하거나, 샘플 파일을 [가져오기]로 불러옵니다.

자주 묻는 질문

이 앱은 어떤 데이터 기반으로 순위를 매깁니까?

Mac Studio M5 Max 48GB 환경에서 직접 측정한 13개 모델의 실측 데이터를 기반으로 합니다. 커뮤니티 글이나 이론적 사양이 아닌 실제 측정값을 사용합니다.

내 맥 메모리에 안 들어가는 모델은 어떻게 표시됩니까?

선택된 맥 메모리 용량에 해당 모델이 들어가지 않으면, 비교 화면의 선택지에서 '(이 맥 메모리에 안 들어감)'으로 표시되어 오작동을 방지합니다.

다른 맥에서 설정을 이어 쓸 수 있습니까?

네, '관심 모델' 탭에서 [내보내기]를 통해 JSON 파일로 저장한 뒤, 다른 기기에서 [가져오기]로 파일을 선택하면 설정이 그대로 복원됩니다.

실제 내 맥 사양이 아닌 예시로 먼저 볼 수 있습니까?

상단의 [예시로 해 보기] 버튼을 누르면 16GB 맥 기준으로 채워진 화면이 표시되어, 10초 만에 앱의 기능을 미리 체험해 볼 수 있습니다.
