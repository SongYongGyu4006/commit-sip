맥 로컬 LLM 고르기

Mac Studio M5 Max 48GB 실측 데이터를 기반으로 내 맥 메모리에 맞는 로컬 LLM을 용도별로 비교하고, 관심 모델을 JSON으로 저장하는 웹 앱입니다.

맥 로컬 LLM 고르기 바로 써 보기 →

개발자와 학생이 커뮤니티 추측성 정보 대신 실제 측정된 수치로 모델을 고를 수 있도록 돕습니다. 내 맥 메모리에 들어가는 모델만 필터링하여 용도별 순위를 제공하고, 두 모델을 나란히 비교해 차이를 명확히 보여줍니다.

쓰는 법

  1. 상단에서 내 맥 메모리 용량과 주 용도(한국어·코딩·도구·속도)를 선택합니다.
  2. 실측 데이터 기반으로 정렬된 모델 목록에서 [예시로 해 보기]를 눌러 화면 구성을 확인합니다.
  3. '두 모델 비교' 탭에서 관심 있는 두 모델을 선택하고 [비교]를 눌러 수치 차이를 확인합니다.
  4. 관심 모델 옆의 [저장] 버튼을 눌러 모델을 브라우저에 보관합니다.
  5. '관심 모델' 탭에서 [내보내기]를 눌러 JSON 파일로 저장하거나 [가져오기]로 불러옵니다.

자주 묻는 질문

이 앱의 데이터는 어디서 왔나요?

Mac Studio M5 Max 48GB 환경에서 직접 측정한 13개 모델의 실측 데이터를 기반으로 합니다.

64GB나 128GB 메모리를 선택하면 어떻게 되나요?

실측은 8~48GB 기준이므로 64GB 이상은 '미실측'으로 표시되며, 해당 모델은 선택 시 안내 메시지만 표시됩니다.

내 맥에 안 들어가는 모델은 비교할 수 있나요?

아니요. 내 맥 메모리에 안 들어가는 모델은 비교 대상에서 제외되며, 선택 시 한국어 안내 메시지로 알려줍니다.

관심 모델 목록을 다른 맥에서 쓸 수 있나요?

네. [내보내기]로 생성한 JSON 파일을 다른 맥의 [가져오기]에 선택하면 설정이 그대로 복원됩니다.
