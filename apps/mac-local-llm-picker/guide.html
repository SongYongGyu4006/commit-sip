맥 로컬 LLM 고르기: 실측 데이터 기반 선택 도구

Mac Studio M5 Max 48GB 실측 데이터를 기반으로 내 맥 메모리에 맞는 로컬 LLM을 골라 보세요. 한국어·코딩·속도별 순위와 두 모델 비교, JSON 내보내기 기능을 제공합니다.

커뮤니티 글만 보고 로컬 AI 모델을 고르는 불편을 덜어 줍니다. Mac Studio M5 Max 48GB에서 직접 측정한 실측 데이터를 바탕으로, 내 맥 메모리에 실제로 들어가는 모델만 필터링합니다. 용도별 순위와 수치 비교를 통해 개발자와 학생이 자신에게 맞는 모델을 확신 있게 선택할 수 있게 합니다.

쓰는 법

  1. 상단에서 내 맥 메모리 용량과 용도(한국어·코딩·도구·속도)를 선택합니다.
  2. 실측 데이터 기반으로 정렬된 모델 순위를 확인하고 상위 모델을 봅니다.
  3. 관심 있는 두 모델을 선택해 실측 수치와 차이를 나란히 비교합니다.
  4. 관심 모델을 브라우저에 저장하고 JSON 파일로 내보내거나 가져옵니다.

자주 묻는 질문

64GB나 128GB 메모리를 선택하면 어떻게 되나요?

이 앱은 Mac Studio M5 Max 48GB에서 측정한 데이터만 보유하고 있어, 64GB와 128GB는 '미실측'으로 표시됩니다. 해당 메모리에 맞는 모델 목록은 제공되지 않으며, 실측 범위(8-48GB) 안내만 뜹니다.

한국어 성능을 어떻게 평가하나요?

실측 데이터에서 한국어 처리 관련 지표를 기반으로 순위를 매깁니다. '한국어 llm 벤치마크' 데이터를 참고하여 모델별 한국어 능력을 수치화해 보여 줍니다.

내 맥 메모리에 안 들어가는 모델은 어떻게 보이나요?

선택한 메모리 용량에 모델이 들어가지 않으면, 해당 모델 옆에 '(이 맥 메모리에 안 들어감)'이라고 표시되어 선택을 방지합니다.

다른 맥에서 설정을 이어받을 수 있나요?

네, '관심 모델' 탭에서 설정을 JSON 파일로 내보내면, 다른 맥이나 새로 연 화면에서 그 파일을 가져와 설정을 복원할 수 있습니다.
