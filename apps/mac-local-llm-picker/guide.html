맥 로컬 LLM 고르기: 실측 데이터 기반 선택 도구

Mac Studio M5 Max 48GB 실측 데이터 기반. 내 맥 메모리에 맞는 로컬 llm을 용도별 순위로 확인하고 비교하세요. 맥 로컬 ai 구축에 도움.

맥 로컬 LLM 고르기 바로 써 보기 →

개발자와 학생이 커뮤니티 추측 대신 실제 측정된 수치로 모델을 고를 수 있게 돕습니다. 내 맥 메모리에 맞는 모델만 필터링하여 용도별 순위를 보여줍니다. 두 모델을 나란히 비교하여 최적의 선택을 지원합니다.

쓰는 법

  1. 상단에서 내 맥 메모리 용량과 사용 용도(한국어·코딩 등)를 선택합니다.
  2. 실측 데이터 기반으로 정렬된 모델 순위 목록을 확인합니다.
  3. '두 모델 비교' 탭에서 관심 있는 두 모델을 선택해 성능 차이를 봅니다.
  4. 관심 모델을 브라우저에 저장하고 JSON 파일로 내보내거나 가져옵니다.

자주 묻는 질문

64GB나 128GB 맥도 사용할 수 있나요?

아니요, 현재 실측 데이터는 8~48GB 범위만 존재합니다. 64·128GB는 선택할 수 없으며, 예전 설정은 자동으로 48GB로 전환됩니다.

이 앱은 어떤 맥에서 가장 정확하나요?

Mac Studio M5 Max 48GB에서 직접 측정한 데이터를 기반으로 하므로, 이 사양과 유사한 애플 실리콘 맥에서 가장 정확한 참고가 됩니다.

내 맥 메모리에 안 들어가는 모델은 어떻게 표시되나요?

비교 화면에서 선택 시 '(이 맥 메모리에 안 들어감)'으로 표시되며, 목록 뒤로 밀려 안내 문구를 함께 띄워 줍니다.

설정 파일을 다른 맥에서 쓸 수 있나요?

네, '관심 모델' 탭에서 내보내면 llmpick-state.json 파일로 저장되며, 다른 맥에서 가져오기 기능을 통해 복원할 수 있습니다.
