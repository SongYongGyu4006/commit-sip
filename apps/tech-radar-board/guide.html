매일 공식 블로그부터 커뮤니티까지 여러 곳을 돌아다니며 기술 소식을 찾아야 하는 개발자와 학생의 번거로움을 덜어줍니다. 17개 출처에서 수집한 데이터를 한 화면에 모아, 지금 가장 화제인 'ai 트렌드 뉴스'와 '개발 뉴스'를 중요도 점수와 함께 보여줍니다. 어떤 소식이 여러 곳에서 동시에 언급되는지 교차 확인하여 진짜 중요한 정보만 빠르게 파악할 수 있습니다.

쓰는 법

  1. 화면 맨 위 필터에서 등급(공식·언론 등)을 선택하거나 [교차 확인만], [관심 주제만] 체크하여 목록을 걸러봅니다.
  2. 상단에 표시된 '지금 가장 큰 소식 3개' 카드를 확인하여 최상위 이슈를 파악합니다.
  3. 소식 목록에서 제목을 클릭하면 원문 링크와 HN 점수 등 출처별 지표가 펼쳐지므로 상세 내용을 확인합니다.
  4. 화면 하단의 '출처 수집 현황'을 통해 각 출처의 수집 성공 여부를 점검합니다.

자주 묻는 질문

이 앱은 어떤 데이터를 사용하나요?

17개의 기술 출처(공식 블로그, 기술 언론, HN, GeekNews, 레딧, GitHub 트렌딩 등)가 매일 수집한 기술 소식 데이터를 사용합니다.

중요도 점수는 어떻게 계산되나요?

0~100점 스케일로, 오늘 수집된 전체 소식 중 해당 소식이 몇 % 안에 드는지 기준으로 산출됩니다.

원문 링크가 안 뜨는 경우가 있나요?

버전 3에서 소식 클릭 시 원문 링크가 안 뜨던 오류를 수정했으며, 클릭 시 상세 정보가 펼쳐지고 다시 클릭하면 접히도록 개선되었습니다.

데이터 파일 없이도 사용 가능한가요?

네, 브라우저로 앱을 열 때 로컬 데이터 파일 읽기에 실패하면 '예시로 해 보기' 버튼을 눌러 샘플 데이터로 화면을 확인할 수 있습니다.
