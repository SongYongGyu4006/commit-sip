freehire 실측 기록 — Go로 만든 IT 채용 오픈소스, 설치 없이 받아서 돌려 봤다

2026년 10월 23일 · 읽는 데 4분
한 줄 요약회사 ATS(채용 관리 시스템)에서 IT 공고를 직접 긁어오는 오픈소스 채용 검색 도구 freehire를 받아, 인터넷 없이 돌릴 수 있는 부분만 실행해 본 기록이다.
▶
60초 영상으로 보기유튜브 커밋 한 모금 쇼츠

무엇인가

freehire는 Workday·Greenhouse·Lever 등 124개 ATS 플랫폼, 320개 소스에서 330만 개 이상의 IT 공고를 직접 크롤링해 하나의 형식으로 정리하고, 중복을 걷어 내 검색할 수 있게 한 오픈소스 프로젝트다. 2026년 6월 7일에 만들어졌고, 확인한 시점에는 5개월 만에 별 2,779개, 포크 268개를 받았다. 라이선스는 MIT다.

검색에는 Meilisearch를, 의미 기반 검색에는 pgvector(벡터로 저장해 의미로 찾는 기술)를 쓴다. 같은 공고가 여러 게시판에 올라와도 하나로 합치고, 스킬·지역·연봉 같은 분류는 사전에 정해 둔 값만 붙인다.

직접 해 본 것

Go도 Docker도 없어서 README Quick start처럼 서버를 올리는 실험은 처음부터 할 수 없었다. 대신 저장소를 받아 읽고, 인터넷 없이 표준 라이브러리만으로 돌아가는 스크립트만 실행했다. 인터넷이 막혀 있는 것도 먼저 확인했다.

실제로 실행한 명령과 결과는 다음과 같다.

python3 scripts/test_discover_boards.py   # 17/17 통과
python3 scripts/test_harvest_boards.py    # 11/11 통과

앞의 것은 ATS 보드 슬러그(고유 식별자)를 뽑는 로직을, 뒤의 것은 Hacker News 위시라이징 포스트를 고르는 로직을 검증한다. 둘 다 통과했다.

슬러그 탐지 패턴을 샘플 텍스트에 적용하니 슬러그 6개(ashby/clipbook, greenhouse/square·verizon 등)가 나왔다. 한국 ATS(tmap, saramin) URL은 패턴에 없어 잡히지 않았다. 서구 ATS 위주로 동작한다는 점을 직접 확인한 셈이다.

공개 API 스펙을 파싱해 보니 엔드포인트가 12개(검색, facet, 유사 공고, 회사, 도시 등)였고, 검색에는 지역·스킬·시니어리티·연봉 등 49개 파라미터가 있다.

이력서와 공고를 맞춰 보는 매칭 로직은 순수 집합 연산이라 Go 없이 다시 구현해 실행했다. 공고의 스킬 5개와 프로필의 스킬 4개를 비교하자 exact 0, adjacent 2, missing 3, coverage 20%가 나왔고, 원문과 같은 결과였다.

못 한 것은 Go 서버·Docker 스택 실행(Go와 Docker가 없음)과 freehire.me API 실측(인터넷 차단, URLError: Operation not permitted 확인)이다.

이 맥에서 쓸 수 있나

이 맥은 Mac Studio, Apple M5 Max, 메모리 48GB, macOS 27.0.1이고 디스크 여유는 약 183GB다. 로컬 AI 모델 서버가 메모리를 약 34GB 상시 쓰고 있다.

README Quick start는 make up으로 Go API, 웹, Postgres, Meilisearch, Redis, S3를 Docker로 올리는 방식이다. 이 맥에는 Go와 Docker가 없어 서버는 실행하지 못했다.

실행할 수 있었던 범위는 표준 라이브러리만으로 도는 스크립트(보드 발견·수확 테스트), 판정 로직 재구현, API 스펙 읽기까지다. 판정 로직은 MIT 라이선스라 필요한 부분만 가져와 다시 구현해도 된다.

이런 분께

  • Go로 데이터 파이프라인(크롤링 → 정규화 → 중복 제거 → 검색 인덱싱)을 공부하려는 분께 맞아요.
  • ATS에서 공고를 긁는 어댑터 패턴이나 검색 facet(분류 기준) 설계가 궁금한 분께 맞아요.
  • 바로 설치해서 쓰려는 분께는 안 맞아요. 전체 스택이 Docker로만 뜨는데, 이 글은 설치·실행까지 다루지 않았으니까요.
  • 한국어·비영어 공고를 얼마나 다루는지는 확인하지 못했습니다. 이 도구는 서구 ATS 위주이고, 한국어 공고가 얼마나 있는지는 인터넷이 없는 환경이라 알아볼 수 없었어요.

주의할 점

라이선스가 MIT라고 데이터까지 MIT인 것은 아니다. 공개 API를 키 없이 쓰면 "개인·비상업적 용도"로만 쓸 수 있고, 자기 서비스에 공고를 보여주려면 유료 데이터 라이선스가 필요하다(API 스펙에 명시).

키 없는 API의 속도 한도는 분당 120회, 하루 2,000회(인하 예정)다. 반복 크롤링이나 다이제스트에는 빠듯하고, 429(요청 초과) 처리도 해야 한다.

한 줄로 줄이면, MIT는 코드에만 해당하고 데이터는 별도 계약이 필요하다.
