무엇인가

TradingAgents는 LLM 에이전트 여러 개가 역할을 나눠 주식 매수·매도를 정하는 프레임워크다. 구조는 실제 트레이딩 회사와 비슷하다. 펀더멘털, 센티먼트(뉴스·SNS에 드러난 시장 분위기), 뉴스, 기술 분석을 맡은 분석가 넷이 동시에 일한다. 이어서 낙관론자와 비관론자 연구원들이 그 결과를 놓고 정해진 형식으로 토론한다. 그다음 트레이더가 매수·매도·보유를 고른다. 리스크 팀이 검토하고 포트폴리오 매니저가 승인하면 시뮬레이션 거래소에서 주문이 나간다.

이 프로젝트가 최근 특히 공을 들인 질문은 "과거 날짜로 돌렸을 때 미래 데이터를 보지 않는가"다. 답은 point-in-time(시간 기준) 규칙이다. 과거 날짜를 요청하면 그 날짜 뒤에 공개된 뉴스나 재무 데이터는 볼 수 없게 막아 둔다. 백테스트 결과를 믿으려면 꼭 있어야 하는 규칙이다. 라이선스는 Apache-2.0이라 상업적으로 써도 되고 재배포해도 된다.

직접 해 본 것

환경은 Mac Studio, Apple M5 Max, 메모리 48GB, macOS 27.0.1이다. 인터넷은 막아 두었고 의존성도 설치하지 않았다. README는 Python 3.11 이상과 pip install .을 전제로 한다. 그런데 이 환경에는 필요한 의존성 18종이 하나도 없었다. 그래서 패키지 임포트는 실패했고, 실제로 돌려 본 건 아래 두 가지다.

첫째, 의존성이 전혀 없는 날짜 규칙 모듈만 파일 경로로 직접 불러와 검증 15개를 돌렸다. 같은 방식으로 재현할 수 있다.

system python: 3.9.6   today (system): 2026-10-28
  PASS  future date clamped
  PASS  non-canonical date canonicalized
  ...
ALL 15 CHECKS PASSED — point-in-time module runs on plain Python, zero dependencies

모듈이 하는 일은 단순해 보인다. 미래 날짜를 요청받으면 실행 날짜로 당겨 온다. 2026-7-3처럼 0이 빠진 날짜는 2026-07-03으로 정규화한다. 읽을 수 없는 날짜는 실행 날짜로 바꿔 우회를 막는다. 날짜 창이 통째로 실행일 이후에 걸리면 길이는 그대로 두고 뒤로 옮긴다. 날짜가 없는 뉴스 항목은 과거 창에서 뺀다. 데이터 소스가 어떤 기간을 관찰하지 못했다면 "뉴스가 없었다"가 아니라 "관측할 수 없었다"고 알려 준다.

둘째, 저장소에 있는 단위 테스트를 일부 돌렸다. 백테스트 채점, OpenAI 호환 공급자 설정, 5단계 등급 파싱이 모델 없이 동작하는지 봤다.

cd repo && ../venv/bin/python -m pytest tests/test_backtest.py tests/test_openai*
104 passed in 1.05s

못 해 본 것도 있다. LLM 실행, 백테스트 전체, CLI는 돌리지 못했다. 셋 다 LLM API나 로컬 모델 엔드포인트, 그리고 Yahoo Finance 같은 네트워크 데이터가 있어야 해서 인터넷을 막은 환경에서는 애초에 안 된다. 그래서 "AI 팀이 실제로 주식을 사고판다"는 핵심 흐름은 이번에 확인하지 못했다.

이 맥에서 쓸 수 있나

이 맥에서는 프레임워크를 실행하지 못했다. README는 Python 3.11 이상을 요구하는데, 이 맥의 시스템 Python은 3.9.6이다. homebrew 쪽에 3.14.8이 있긴 했다. 하지만 의존성 18종을 깔려면 인터넷이 필요하다.

로컬 모델 쪽도 애매하다. 이 맥의 로컬 AI 모델 서버가 메모리를 약 34GB 늘 쓰고 있다. 그래서 48GB 메모리로 이 프레임워크의 LLM 호출까지 맡기에는 여유가 모자랄 수 있다. 프레임워크는 로컬 Ollama나 OpenAI 호환 서버를 지원한다. 다만 이 맥의 로컬 서버가 OpenAI 호환 /v1을 제공하는지는 확인하지 못했다.

정리하면 이렇다. 의존성을 설치하고 인터넷이 열려도 남는 걸림돌은 Python 버전과 메모리다. 그리고 이번 시험 조건인 "설치 없이"로는 LLM을 돌릴 수 없다.

이런 분께

맞는 분:

  • LLM 다에이전트 구조를 코드로 직접 들여다보고 싶은 개발자
  • 과거 날짜 백테스트에서 미래 데이터 누수(look-ahead bias)를 어떻게 막는지 참고하려는 사람
  • Apache-2.0 라이선스로 마음껏 공부하고 고쳐 쓰고 싶은 사람

맞지 않는 분:

  • 이대로 주식을 사고팔려는 사람(README에도 "투자 조언이 아님"이라고 적혀 있다)
  • 로컬 모델로 안정적으로 돌리고 싶은 사람(결과가 모델 품질에 달려 있다)
  • 설치 없이 바로 돌려 보고 싶은 사람(설치와 인터넷이 필수다)

주의할 점

첫째, 이 프레임워크의 LLM 출력은 매번 같지 않다. 같은 종목, 같은 날짜로 돌려도 결과가 달라질 수 있다. README도 이를 연구 도구의 특성이라고 설명한다.

둘째, 데이터를 Yahoo Finance, Reddit, StockTwits 같은 비공식 피드에서 가져온다. 외부에서 막히거나 피드가 바뀌면 동작이 불안정해질 수 있다.

셋째, 이번 시험은 설치 없이 일부만 확인한 것이다. 날짜 규칙 검증 15개와 단위 테스트 104개가 통과했다고 해서 프레임워크 전체가 안전하다는 뜻은 아니다. 특히 LLM 실행, 백테스트, CLI는 돌려 보지 못했다.
