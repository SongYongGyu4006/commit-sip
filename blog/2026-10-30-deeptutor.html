DeepTutor: AI 개인 튜터 오픈소스, 설치 없이 받아서 돌려 봤다

2026년 10월 30일 · 읽는 데 4분
한 줄 요약강의 자료를 넣으면 질의응답과 퀴즈를 만들어 주는 AI 튜터 "DeepTutor"를 받아, 설치하지 않고 복습 계산 코드만 따로 떼어 돌려 봤다.

무엇인가

HKUDS가 공개한 DeepTutor는 사용자가 올린 강의 자료로 지식 베이스를 만들고, 그 자료를 근거로 질의응답과 퀴즈를 만들어 주는 "평생 맞춤형 튜터" 오픈소스다. LLM이 도구를 고르고 단계별로 역할을 나누는 플러그인 구조이고, 정독, 반복 암기, 마스터시 경로, 수학·과학 시각화, 영상 강의 같은 기능이 들어 있다.

최신 릴리스는 v1.7.0(2026.10.28)이다. 규모는 .py 2,074개 · .tsx 778개 · .ts 710개, 약 65.4MB다. 프론트엔드는 Next.js 16이고, 진입점은 CLI·WebSocket API·Python SDK 세 가지다. 전체를 실행하려면 인터넷 연결과 LLM API 키, Node 22가 필요해서 오프라인 재현은 어렵다.

라이선스는 Apache-2.0이다. 상업적 사용과 재배포가 가능하고, 원본 고지와 변경 표시 조건을 따라야 한다. 다만 실행에 쓰는 LLM API의 라이선스(학습에 사용 금지 같은 조건)는 그대로 적용된다.

직접 해 본 것

GitHub 저장소를 받아 설치 없이 살펴봤다. 새 패키지는 깔지 않고 기계에 이미 있던 python3.14로 실행했다. 원본은 건드리지 않고 복사본으로만 실험했다.

가장 제대로 해 본 일은 반복 학습(스페이시드 리피티션) 계산 코드를 따로 떼어 실행한 것이다. 채점, 마스터시, 스케줄러 모듈 세 개를 복사하고, 의존성은 표준 dataclass 스투브로 바꿔 실행했다.

  • 채점: 기대값 8/8 통과. 빈 답은 메타인지 오류로, 내용이 있는 오답은 적용 오류로 분류한다.
  • 마스터 정도(주제별 숙달 정도를 0~1로 계산하는 값): 1회 정답이면 0.5, 2회면 0.8, 3회 이상이면 1.0. 한 번 맞혔다고 마스터로 치지 않게 한 수치다.
  • 스케줄러: 정답이면 간격이 길어지고 오답이면 짧아지며, 큐는 망각 위험이 높은 순으로 정렬된다. 다시 실행해도 결과가 같은(결정론적) 것을 확인했다.

핵심 기능인 지식 베이스 RAG와 퀴즈 생성은 해 보지 못했다. 이번 시험에서는 설치를 하지 않았기 때문이다. 실제로 실행한 명령은 세 개다.

bash scratch/c1.sh
bash scratch/c2.sh
bash scratch/c3.sh

첫 명령은 1.3초 만에 실패로 끝났고(종료 코드 1), 두 번째는 73.7초 뒤에 실패했다. 세 번째만 1.1초 뒤에 종료 코드 0으로 끝났다. 그래서 강의 자료로 지식 베이스를 만들어 질의응답을 하는 전체 흐름은 이번에 검증하지 못했다.

이 맥에서 쓸 수 있나

이 글을 쓴 맥은 Mac Studio, Apple M5 Max(arm64), 메모리 48GB, macOS 27.0.1(빌드 26A434)이고 디스크 여유는 약 140GB다. 로컬 AI 모델 서버(Splash 1.2.0)가 메모리를 약 34GB 상시 쓰고 있다.

DeepTutor 설치 문서는 pip install -r requirements/full.txt와 pip install -e . --no-deps 또는 모듈형 휠을 전제로 하고, openai·mcp·faiss 같은 무거운 의존성을 고정해 둔다. 인터넷으로 설치하는 것이 전제인 셈이다. 이번에는 설치를 하지 않았고 인터넷도 없는 환경이라, 문서가 말하는 "오프라인 재현 불가"가 그대로 적용됐다. 그래서 전체 앱을 이 맥에서 돌린다고 말하기는 어렵다.

반면 따로 떼어 실행한 채점·마스터시·스케줄러 코어 세 개는 의존성 설치가 필요 없어서 이 맥에서 실제로 돌아가는 것을 확인했다. 이 코어는 LLM 없이도 검증할 수 있고, Apache-2.0이라 가져다 쓰는 조건도 분명하다. 전체 앱(무거운 의존성, Node 22, LLM 키)은 이 환경에 맞지 않지만, 복습 계산 코어만은 이 맥에서도 쓸 수 있다.

이런 분께

맞아요: 반복 학습·복습 스케줄링 로직을 자기 프로젝트에 넣고 싶은 개발자. LLM 없이 검증할 수 있는 작은 코어를 찾는 분.

안 맞아요: 강의 자료 RAG 튜터를 통째로 바로 쓰고 싶은 분(이번에는 설치 없이 봤고 전체 실행은 검증하지 못했다). 오프라인에서 전체 앱을 돌리려는 분(인터넷, LLM 키, Node 22가 필요하다).

주의할 점

전체 실행에는 인터넷과 LLM API 키가 필수다. API별 라이선스(학습 사용 금지 등)도 그대로 적용된다.

deeptutor/learning/ 코드는 pydantic 모델에 의존해서, 그대로 쓰려면 pydantic을 설치해야 한다. 이번에는 스투브로 우회해 실행했으니, 스투브가 실제 모델과 다르면 결과가 왜곡될 수 있다.

마스터 정도를 계산하는 모듈에는 한 줄이 줄바꿈으로 끊겨 있는 곳이 있다. 그대로 옮겨 적으면 버그처럼 보일 수 있으니, 복사할 때는 1줄 단위 그대로 가져오길 권한다.

서브폴더별 별도 라이선스(NOTICE, vendor) 파일이 있는지는 확인하지 못했다.
