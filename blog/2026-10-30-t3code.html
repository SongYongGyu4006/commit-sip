AI 에이전트맥 활용

Claude Code·Codex, 폰에서 원격으로 돌리는 오픈소스 T3 Code — 직접 받아서 해봤다

2026년 10월 30일 · 읽는 데 4분
한 줄 요약로컬에 깔아둔 AI 코딩 도구를 스마트폰·웹·데스크톱 앱에서 원격으로 다루게 해 주는 오픈소스다. 설치 없이 저장소만 받아 코드를 읽었고, 핵심 기능 2가지를 직접 돌려봤다.

무엇인가

T3 Code(pingdotgg/t3code)는 GitHub 별 32,378개, 포크 8,578개를 기록한 프로젝트다. 2026년 2월에 만들어져 9개월 정도 됐고, 라이선스는 MIT다.

원리는 이렇다. 서버가 Claude Code, Codex, Cursor, Grok Build, OpenCode, Google Antigravity 같은 도구를 자식 프로세스(부모 프로그램이 띄워서 관리하는 별도 프로그램)로 실행하고, 작업이 진행되는 모습을 화면에 실시간으로 보여준다. README는 이걸 "에이전트 하네스"라고 부른다. 에이전트(대신 일을 해 주는 AI 프로그램)를 줄에 매어 조종한다는 뜻이다.

직접 해 본 것

저장소를 받은 뒤 의존성은 설치하지 않고 인터넷도 쓰지 않은 채, Node로 돌릴 수 있는 것만 골라 실행했다.

첫째, 핵심 기능인 "턴 단위 자동 백업"을 재현해 봤다. T3 Code는 에이전트가 작업 한 번(턴)을 마칠 때마다 git(코드 버전 관리 도구)의 숨은 참조(ref: 커밋을 가리키는 이름표)로 체크포인트를 남긴다. 필요하면 그 시점과 지금의 차이를 diff(변경 내역)로 보여주거나 그 시점으로 되돌린다. 임시 git 저장소 두 개를 만들어 커밋하고 체크포인트 두 개를 잡은 뒤, 둘 사이 차이를 diff로 확인했다(한 파일 4줄 추가). 이어서 첫 체크포인트로 되돌리자 추가했던 파일이 사라졌다. 예상대로였다.

둘째, 저장소에 들어 있는 평가 스크립트 하나를 그대로 가져와 돌렸다. 특정 패턴의 코드가 테스트 블록 안에 있는지 판별하는 함수인데, 정상 케이스는 통과하고 엉뚱한 코멘트를 붙인 케이스는 실패로 처리됐다. "아무것도 검사하지 않는 테스트"를 자동으로 감점하는 평가 회로가 실제로 있고, 동작도 한다는 얘기다.

못 해 본 것도 있다. T3 Code 서버를 제대로 띄우려면 의존성 설치가 필요해서 하지 않았다. 실행을 시도해 보긴 했는데 필요한 모듈이 없어 실패했다. 유료 API 키가 필요한 다른 평가 항목도 돌리지 못했다. 그래서 서버가 에이전트를 원격으로 조종하는 전체 흐름은 아직 직접 확인하지 못했다.

이 맥에서 쓸 수 있나

이 글을 쓴 맥은 Mac Studio, Apple M5 Max(arm64), 메모리 48GB, macOS 27.0.1(빌드 26A434)이다. 로컬 AI 모델 서버가 메모리를 약 34GB씩 상시 쓰고 있다.

T3 Code README에는 CPU·메모리 같은 최소 사양이 나와 있지 않다. 그래서 이 맥이 요구 사양보다 여유가 있는지 없는지는 따질 수 없다.

확인할 수 있는 것만 적으면 이렇다. 저장소 전체가 약 334MB라 디스크 여유 공간(약 168GB)에 비하면 부담이 작다. 메모리는 모델 서버가 상시 쓰는 34GB를 빼면 약 14GB가 남는다. T3 Code는 Node 서버와 Electron 데스크톱 앱을 함께 띄우니 이 안에서 돌아가야 한다. 실제로 감당할 수 있는지는 실행해 보지 않아 확인하지 못했다.

하나 더 있다. 이 맥에는 Claude CLI가 이미 깔려 있어서, T3 Code를 쓴다면 바로 붙여 돌릴 수 있다. Codex·Cursor는 없다. README에 따르면 이런 도구가 하나만 있어도 T3 Code는 동작한다.

이런 분께

이런 분께 맞다:

  • 로컬에서 Claude Code나 Codex를 이미 쓰고 있고, 밖에서도 스마트폰으로 진행 상황을 보거나 중간에 지시를 내리고 싶은 분
  • 에이전트가 코드를 망가뜨릴까 걱정돼, 턴마다 자동 백업(체크포인트)으로 되돌릴 수 있었으면 하는 분
  • 클라우드 서비스 구독이 부담스러워 전부 로컬에서 돌리고 싶은 분

이런 분께는 안 맞는다:

  • AI 코딩 도구를 아직 써 본 적이 없는 분 (프로바이더 CLI를 미리 깔고 로그인해 둬야 한다)
  • 폰으로 원격 조작하는 게 아니라 로컬에서 편하게 쓰는 게 목적인 분
  • Claude Code나 Codex 같은 도구를 로컬에 설치하고 로그인해 두지 않은 분 (이 도구는 그런 도구를 실행해 줄 뿐, AI를 새로 만들어 주지는 않는다)

주의할 점

첫째, 원격 접속 방식. 저장소 문서에는 T3 Connect라는 공용 터널 방식이 기본으로 나와 있다. 이걸 켜면 에이전트 트래픽과 코드 차이가 T3 운영사 인프라를 거친다. 로컬 네트워크나 Tailscale(사설망 도구) 페어링으로만 쓰는 편이 안전하다.

둘째, 구독 사용량이 빨리 닳을 수 있다. 이 도구로 Claude·Codex 같은 도구를 계속 돌리면 전보다 사용량이 빨리 소진될 수 있다.

셋째, 배포물은 검증하지 못했다. 실제로 설치해 쓰는 컴파일된 앱이 이 오픈소스 소스와 똑같은지는 확인하지 못했다. 인터넷이 막힌 환경이라 릴리스 파일을 받아 비교할 수 없었다. 소스와 릴리스가 다를 가능성은 남아 있다.

넷째, 프로젝트 쪽에서 README에 "아직 매우 초기 단계, 버그를 예상하라"고 적어 두었다.
