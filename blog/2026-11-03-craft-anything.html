Craft Anything, 설치 없이 받아서 직접 살펴본 기록

2026년 11월 3일 · 읽는 데 5분
한 줄 요약어떤 소프트웨어가 어떻게 돌아가는지 실제로 검사하고, AI 코딩 에이전트가 그것을 다시 만든 뒤 원본과 비교해 고쳐 주는 오픈소스 프로젝트다. 순수 Rust로 쓰였고, 2026년 10월 31일 공개 후 3일 만에 별 6,543개를 받았다. early alpha 단계이며, 라이선스는 MIT 또는 Apache-2.0 중 선택한다.

무엇인가

웹사이트, 앱, 게임, 파일 같은 대상을 지정하면 4단계를 거친다. 먼저 원본을 조사(Study)하고, 코딩 에이전트가 새 프로젝트를 작성(Build)한다. 그 결과를 원본과 비교(Check)해 차이 나는 부분을 찾아 고치면(Ready) 끝난다. 웹사이트는 화면 폭 3가지로, 게임은 게임 자체의 자동 테스트로 비교한다.

도구는 모두 314개이고, 명령줄, MCP, AI 에이전트, 데스크톱 앱에서 똑같이 쓸 수 있다. MCP는 AI 도구끼리 도구를 주고받는 표준 규약인데, 이것이 있으면 에이전트가 앱 없이도 이 엔진을 직접 움직일 수 있다.

기본값은 "클린룸" 모드다. 이 모드에서는 원본 안쪽(코드, 파일, 페이지 소스)을 전혀 읽지 않는다. 사용자가 올린 사진과 방문자에게 보이는 화면(스크린샷, 보이는 텍스트, 레이아웃, 색, 폰트)만으로 재구성한다. "딥" 모드로 바꾸면 원본 내부의 코드와 JavaScript까지 읽는다.

빌드하려면 이 컴퓨터에 로그인된 코딩 에이전트가 있어야 하며, Claude Code를 처음부터 지원한다. 이 프로젝트는 사용자 계정을 대신 처리하지 않고, 사용자가 쓰는 에이전트 프로그램을 그대로 실행하는 방식이다.

직접 해 본 것

설치는 하지 않았다. 시험 환경에 인터넷이 없어 설치할 수 없었고 Rust 도구도 없어서, 컴파일된 Rust 엔진은 실행하지 못했다. 대신 저장소의 파일 형식 파싱 로직(아카이브, 데이터베이스 같은 파일을 읽는 부분)을 외부 의존성 없이 Python으로 옮겨 쓰고, 시험 파일 다섯 개를 만들어 돌려 봤다.

실행한 것은 이 한 건뿐이다.

python3 run_experiments.py

시험 파일 다섯 개는 모두 표준 라이브러리로 만들었다. 작은 zip 아카이브, SQLite 데이터베이스, 랜덤 바이트에 가짜 zip 마커를 붙인 적대적 입력, 실제 앱의 로컬 상태 데이터베이스 복사본, 합성으로 만든 웹 트래픽 기록(HAR)이다.

확인한 결과는 다음과 같다.

  • zip 파일은 형식 검출이 맞았고, 안의 파일 목록도 표준 라이브러리 결과와 같았다. 소스 로직과도 대조했다.
  • 가짜 마커를 넣은 적대적 입력은 크래시나 패닉 없이 "인식 불가"로 기록됐다. 어떤 입력에도 크래시가 나면 안 된다는 이 저장소의 원칙과 맞는 결과였다.

확인하지 못한 것도 있다. SQLite 데이터베이스 테스트는 옮겨 쓴 코드의 버그 때문에 실행이 중단됐다. 버그를 원본 소스와 대조해 고쳤지만 다시 실행하지 않아, 고쳐졌는지는 확인하지 못했다. 나머지 두 파일(실제 앱 데이터베이스, 웹 트래픽 기록)도 그 앞에서 실행이 멈춰 결과가 없다.

Rust 엔진을 실행하지 못했으므로 314개 도구 전체, 재구축 워크플로(조사→작성→검사→완료)의 실제 동작, 클린룸/딥 모드, MCP 서버, 데스크톱 앱은 모두 확인하지 못했다.

이 맥에서 쓸 수 있나

공식 문서가 밝힌 요건은 Rust 1.97 이상 하나뿐이다. 하드웨어나 운영체제 요건은 적혀 있지 않다.

그래서 이 컴퓨터(Mac Studio, Apple M5 Max, 메모리 48GB, macOS 27.0.1, 디스크 여유 약 112GB)의 사양이 요구치보다 높은지 낮은지 단정할 근거가 없다. 요구 사양에 해당 항목이 없기 때문이다.

참고로 이 Mac에는 지금 Rust 도구가 설치되어 있지 않다. README의 빌드 명령은 cargo run --release -p craft-anything(데스크톱 앱)과 cargo install --path apps/craft-anything-cli(CLI) 두 가지다. macOS용 데스크톱 앱은 서명·승인을 마친 universal 빌드이고, 릴리스 페이지에서 내려받을 수도 있다.

결론적으로, 이 프로젝트가 이 Mac에서 돌아가는지는 확인하지 못했다. 확인된 사실은 Rust 1.97 이상이 필요하다는 것, 그리고 시험 환경에서 빌드와 실행을 하지 않았다는 것뿐이다.

이런 분께

맞는 사람:

  • 리버스 엔지니어링이나 정적 분석에 관심이 있고, AI 에이전트가 코드 프로젝트를 실제로 움직이는 과정을 보고 싶은 개발자.
  • 314개 도구가 모두 CLI/MCP로 열려 있는 구조 자체가 참고 자료가 되는 사람.

안 맞는 사람:

  • 바로 실무 파이프라인에 넣어야 하는 사람. early alpha이고, 여러 기능이 "부분적으로만 되는" 단계다.
  • "이 웹사이트 클론하고 싶어요"라고 말하기만 하면 되는 완제품을 기대하는 사람.

주의할 점

  • early alpha다. 프로젝트 상태 문서에 "아직 부분적으로만 되는" 항목(앱·게임 동작 검사 등)이 여럿 있다.
  • GitHub 배지에는 Apache-2.0으로 표시되지만, 저장소 내부 문서와 메타데이터는 "MIT 또는 Apache-2.0" 택일 라이선스로 되어 있다. 둘이 맞지 않으니 저장소 내 문서를 기준으로 봐야 한다.
  • 딥 모드는 다른 사람 소프트웨어의 코드와 JavaScript를 읽는다. 공식 문서도 "자기 소유이거나 검사가 허용된 소프트웨어에만" 쓰라고 밝힌다.
  • 이미지/3D 생성에는 fal.ai 외부 API 키가 필요하고, 사용량에 따라 실제 비용이 든다.
  • Rust 1.97 이상이 필요하므로, 오래된 도구를 쓰고 있다면 먼저 업데이트해야 한다.
  • "ArtCraft"라는 이름과 로고는 상표다. 이 프로젝트 안에서만 수정 없이 쓸 수 있고, 포크할 때는 제거해야 한다.
