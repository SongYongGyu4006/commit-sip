gstack: Claude Code를 가상 개발 팀으로 만드는 오픈소스, 설치 없이 직접 봤다

2026년 11월 5일 · 읽는 데 5분
한 줄 요약gstack은 AI 코딩 도구인 Claude Code에 CEO·디자이너·QA 등 50여 개 역할 스킬을 얹어, 혼자 개발해도 팀처럼 돌아가게 해 주는 MIT 라이선스 오픈소스다. 이번에는 인터넷 없이 저장소를 받아 설치하지 않고 살펴봤고, "AI 냄새나는 디자인"을 잡는 판정 규칙만 따로 재구성해 돌려 봤다.

60초 영상으로 보기유튜브 커밋 한 모금 쇼츠

무엇인가

gstack은 YC(인공지능 스타트업 지원 기관)의 게리 탄(Garry Tan) 회장이 공개한 도구 모음이다. 본체는 전부 Markdown 문서로 된 지시문(스킬)이다. AI 에이전트에게 어떤 역할로 행동할지 알려 주는 문서이고, 이 문서를 읽은 에이전트가 해당 역할을 수행한다.

스킬은 CEO(제품 방향 검토), 엔지니어 매니저(구조 확정), 디자이너, 리뷰어(버그 탐색), QA(실제 브라우저로 확인), 보안 담당, 릴리스(배포) 등으로 나뉜다. 실제 스프린트 순서(생각 → 계획 → 개발 → 리뷰 → 테스트 → 배포 → 회고)대로 이어지게 설계했다.

저장소 규모는 별 139,109개, 포크 20,613개(2026-11-05 00:19 KST 기준)다. 언어는 TypeScript, 라이선스는 MIT(저작권 고지만 포함하면 사용·복제·수정·배포가 자유롭다)다. 2026-03-11에 생성돼 약 8개월 된 저장소다.

직접 해 본 것

저장소를 받아 인터넷 없이, 설치도 하지 않고 살펴봤다.

첫째, MIT 라이선스 전문을 확인했다. 라이선스 파일 전문과 MD5 해시(파일 내용 요약 값)까지 대조했고, 서드파티 라이선스 파일도 함께 들어 있었다.

둘째, 스킬 문서를 읽었다. 디자인 리뷰 스킬 본문은 874줄이고, 템플릿 문서(원본)에서 자동으로 생성된다. 이 스킬은 11가지 "AI 슬롭" 패턴(보라색 그라데이션, 3단 카드 그리드, 이모지 장식, 기본 폰트 등)으로 디자인 초안을 판정한다. "AI 슬롭"은 AI가 너무 많이 만들어 내서 어느새 클리셰가 된 디자인 요소를 말한다.

셋째, 이 11가지 판정 규칙을 표준 파이썬으로 약 50줄짜리 검사 스크립트(패턴 매칭으로 파일만 검사하는 프로그램)로 재구성해 돌려 봤다.

  • 일부러 AI 스타일로 쓴 한국어 웹앱 초안(보라 그라데이션 히어로 + 3단 카드 + 이모지 + 기본 폰트) → 11개 항목 중 7개 위반
  • 같은 제품을 gstack 원칙으로 다듬은 버전(단일 강조색, 간결한 문구) → 위반 0건

두 초안을 구분하는 것까지는 확인했다. 다만 정적 텍스트 패턴 매칭이라, 원본이 하는 스크린샷(화면 이미지) 기반 판단까지는 따라가지 못한다. 원본도 이 둘을 구분해 두고 있다.

넷째, 디자인 리뷰 스킬에서 판정 기준(11가지 패턴 + 6개 평가 항목)만 뽑아 더 짧은 문서로 다시 써 두었다. 앞서 만든 검사 스크립트를 같은 초안 2종에 다시 돌려 7건/0건을 재확인했다.

못 해 본 것도 있다. 설치 스크립트는 bun(JavaScript 런타임, 즉 JS 코드를 실행하는 프로그램)과 브라우저 다운로드가 필요해 실행하지 않았다. 브라우저 QA, iOS 기기 테스트, 배포 파이프라인도 네트워크와 외부 계정이 필요해 돌리지 못했다. 실제로 돌린 것은 gstack의 지시문(문서)과 그 재구현분뿐이다.

이 맥에서 쓸 수 있나

내 환경은 Mac Studio, Apple M5 Max(arm64), 메모리 48GB, macOS 27.0.1(빌드 26A434), 디스크 여유 약 144GB다. 로컬 AI 모델 서버가 메모리 약 34GB를 상시 사용 중이다.

gstack 공식 요구 사양은 Claude Code, Git, bun v1.4.2 이상(윈도우는 Node.js)이고, macOS에서는 브라우저 "Aside"를 권장한다. 이 권장 사양은 "macOS 15+"라서 macOS 27.0.1이면 조건을 충족한다.

다만 이번에는 설치하지 않았으므로 gstack이 이 Mac에서 실제로 돌아가는지는 확인하지 못했다. bun이 없는 상태라 스크립트는 실행할 수 없고, 브라우저 기능과 외부 리뷰는 네트워크가 필요하다. 스킬 문서는 MIT라 가져와 재구성할 수 있으니, 앞서 한 방식처럼 하면 이 환경에서도 문서를 검토하는 수준으로는 써 볼 수 있다.

이런 분께

맞아요:

  • Claude Code나 AI 코딩 도구를 쓰면서 리뷰·QA·배포까지 더 체계적인 개발 흐름을 원하는 분
  • 스킬 문서가 전부 Markdown이라는 점을 보고, 판단 기준(디자인 판정, 코드 리뷰 룰)만 골라 자기 환경에 맞게 다시 써 보고 싶은 분
  • MIT 라이선스라 자유롭게 가져와 고쳐 쓸 수 있는 도구를 찾는 분

안 맞아요:

  • 브라우저 기반 QA, iOS 실기기 테스트, 릴리스 자동화 같은 gstack의 대형 기능을 바로 쓰고 싶은 분
  • bun 설치 없이 gstack이 통째로 돌아갈 거라 기대하는 분(실제로는 설치·브라우저·네트워크가 필요하다)

주의할 점

bun이 전제다. 설치, 자동 업데이트, 바이너리(컴파일된 실행 파일) 모두 bun을 기준으로 한다.

자동 업데이트가 기본으로 켜져 있다. 팀 모드(team mode, 같은 팀원에게 gstack을 공유하는 모드)는 stable 채널 기준 2주 주기로 태그된 릴리스를 받아 자동 갱신한다. 스킬 내용이 바뀌면 리뷰·판정 기준도 같이 바뀌므로 버전을 고정해 두는 게 좋다.

서드파티 라이선스가 함께 들어 있다. Apache-2.0 등 서드파티 라이선스 파일이 저장소에 있는데, 각각 어떤 파일에 적용되는지는 확인하지 못했다.

README의 성과 수치는 작성자 환경이 전제다. "10개 스프린트 병렬" 같은 수치는 게리 탄 회장이 매일 쓰는 환경(클라우드)을 전제로 한 것이다. 로컬에서 같은 효과가 나오는지는 확인할 수 없었다.
