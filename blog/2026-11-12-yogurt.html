8GB만으로 로컬 AI 회의록? 오픈소스 Yogurt 설치 없이 코드 직접 돌린 기록

2026년 11월 12일 · 읽는 데 5분
한 줄 요약Yogurt는 회의 앱에 봇을 넣지 않아도 마이크와 시스템 소리를 녹음해 전사하고, 요약·담당자·다음 단계·리마인더까지 로컬에서 만들어 주는 무료 오픈소스 앱이다. 이 글은 앱을 설치해 쓴 기록이 아니다. 저장소를 받아 코드를 읽고, 설치 없이 돌릴 수 있는 부분만 실행해 봤다.

무엇인가

Frigade가 만든 개인용 AI 회의 기록 데스크톱 앱이다. 특징은 두 가지다. 하나는 미팅 참가 봇 없이 마이크와 시스템 소리를 직접 녹음한다는 점이다. 다른 하나는 전사(녹음 음성을 글자로 바꾸는 작업)부터 요약·담당자·다음 단계·리마인더 생성까지 모든 처리를 이 컴퓨터 안에서만 한다는 점이다. 서버에 올리지 않고 사용 추적 데이터도 보내지 않는다.

구성은 Electron + TypeScript로 만든 앱에, 녹음·콜 감지·AI 앱 연동을 맡는 네이티브(Rust) 모듈이 붙는다. 음성 전사에는 whisper.cpp, 요약과 질의응답에는 llama.cpp 기반 모델 엔진을 쓴다. 첫 실행 때 Hugging Face에서 모델 파일을 받고, 받은 파일은 해시로 검증한다. 라이선스는 MIT여서 저작권 표시만 하면 상업적 사용, 재배포, 수정, 판매까지 가능하다. GitHub 별은 현재 149개다.

직접 해 본 것

시험은 인터넷에 연결하지 않은 상태에서 설치 없이 했다. npm·pnpm 설치도 할 수 없었고, 빌드 도구가 필요한 네이티브 코드(Electron·Rust)도 돌릴 수 없었다. 그래서 저장소 원본 코드를 그대로 실행할 수 있는 범위만 돌렸다. 앱의 핵심인 "내 하드웨어에 맞는 모델을 골라 주는" 선택 로직과 모델 목록 검증 로직이다.

node --experimental-strip-types --experimental-loader ./fix-extensions.mjs pick-test.ts

실제 선택 로직이 실제 목록의 8개 모델을 8가지 하드웨어에 대입해 평가했다. 이 맥(M5 Max, 통합 메모리 48GB, 디스크 여유 118GB) 항목에서는 Gemma 4 26B를 추천했고, 컨텍스트 16384, 예상 속도 51.7 tok/s, 디스크 부족 0GB가 나왔다. 다만 51.7 tok/s는 대역폭 표로 추정한 값이지 실제 속도가 아니다. 120B 모델은 메모리를 넘어서 목록에서 빠졌다.

node --experimental-strip-types --experimental-loader ./fix-extensions.mjs catalog-test.ts

모델 목록 검증 로직에 실제 목록과 라이선스 파일을 넣었더니 8개 모델, 4개 음성 인식 엔진, 임베딩 모델, 전사 서버가 모두 검증을 통과했다(ok: true). 음성 인식 엔진 선택도 확인했다. 이 맥과 16GB 맥은 빠른 엔진, 8GB 맥은 가벼운 엔진을 골랐고, Windows·Linux는 빠른 순서대로 내려가는 순서를 택했다.

못 해 본 것도 있다. 전체 데스크톱 앱과 네이티브 모듈은 빌드 도구가 없고 인터넷도 막혀 있어 실행하지 못했다. 검증 로직은 임시 대체 모듈로 돌렸기 때문에 실제 라이브러리에서 어떻게 동작하는지는 확인하지 못했다. 51.7 tok/s도 예측값일 뿐 실측이 아니다. 내가 후보로 생각한 31B·30B 모델은 목록에 없어서 이 선택 로직에 넣어 보지도 못했다. 이 부분은 추측하지 않았다.

이 맥에서 쓸 수 있나

내 사양은 Mac Studio, Apple M5 Max 칩, 메모리 48GB, macOS 27.0.1, 디스크 여유 약 118GB다. 여기에 로컬 모델 서버가 상시로 메모리를 약 34GB 쓰고 있다.

Yogurt의 요구 사양은 macOS 14.4 이상(Apple Silicon)에 메모리 8GB다. Windows 10 2004 이상, Ubuntu 22.04 이상도 지원한다. macOS 버전(27.0.1 ≥ 14.4)과 메모리(48GB ≥ 8GB)는 요구치를 넘는다.

문제는 동시 실행이다. Yogurt의 노트 모델이 약 14GB를 쓰고, 여기에 컨텍스트(KV 캐시, 모델이 앞선 문장을 기억하려고 쓰는 작업 메모리)와 오버헤드가 더해진다. 로컬 모델 서버가 이미 약 34GB를 잡고 있어서, 둘을 함께 띄우면 통합 메모리 48GB로는 모자라 스와핑(메모리 내용을 디스크로 넘기는 것)이 생길 수 있다.

이런 분께

맞아요: 회의 참가 봇 없이 회의 내용을 로컬에서 기록하고 요약하고 싶은 분. "내 컴퓨터에 어떤 모델이 들어가는지"를 실행하지 않고 계산해 보고 싶은 분. 음성 인식을 실시간으로(클립 시간의 절반 안에) 돌리는 기준을 참고하고 싶은 분.

안 맞아요: 앱 설치 후기까지 기대하는 분. 이미 로컬 모델 서버로 48GB 대부분을 쓰고 있는 분. 메모리가 8GB보다 적은 PC를 쓰는 분. 8GB는 최소치일 뿐이라 다른 작업을 함께 돌리려면 여유가 더 필요하다.

주의할 점

라이선스를 한 줄로 말하면, MIT라 코드 자체는 자유롭게 쓸 수 있다. 다만 앱 UI 일부(제3자 컴포넌트)에는 Commons Clause(원저작자가 정한 추가 사용 조건)가, 임베딩 모델에는 Gemma 사용 약관이 따라붙는다. 앱을 통째로 다른 제품이나 서비스에 넣어 배포한다면 이 조건도 함께 따라야 한다. 코드를 참고하거나 기능을 가져다 쓰는 정도라면 MIT가 적용된다.

첫 실행 때는 모델 파일(48GB 맥 기준 약 14GB, 더 큰 맥은 63GB)을 Hugging Face에서 받고 해시로 검증한다. 이 다운로드는 내가 해 보지 못했다.

선택 로직의 대역폭 표에는 M5 Max가 없어서 "Apple M5" 값(153GB/s)으로 계산한다. 그래서 이 맥의 예상 속도는 실제보다 낮게 나온다(실측 대역폭은 546~556GB/s로 추정). 51.7 tok/s는 하한선쯤으로 보면 된다.
