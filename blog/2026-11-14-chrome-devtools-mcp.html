chrome-devtools-mcp 설치 없이 받아 봤다: MCP 통신만 확인, 원격 수집 기본 on

2026년 11월 14일 · 읽는 데 4분
한 줄 요약Google이 낸 에이전트용 Chrome DevTools 도구를 받아서 설치 없이 살펴봤다. MCP 통신 규격은 직접 확인했지만, 실제 브라우저 제어와 성능 트레이스는 돌려보지 못했다. 대신 코드를 읽다가 사용 정보를 기본값으로 Google에 보내는 설정을 발견했다.

무엇인가

chrome-devtools-mcp는 코딩 에이전트가 실행 중인 Chrome을 직접 보고 점검할 수 있게 해 주는 도구다. MCP(Model Context Protocol) 서버로, MCP는 AI 모델이 외부 도구를 호출할 때 쓰는 공통 규격이다.

에이전트가 성능 트레이스 기록, 네트워크 요청 분석, 스크린샷, 콘솔 메시지를 직접 측정한다. puppeteer(브라우저를 프로그램으로 조작하는 라이브러리) 기반 자동화도 지원한다. 최신 버전 1.13.0은 2026년 11월 11일에 나왔고, 라이선스는 Apache-2.0이라 상업적으로 써도 된다.

직접 해 본 것

인터넷 연결 없이, 설치도 하지 않고 저장소만 받아서 살펴봤다.

MCP 통신 규격 확인. hello-world 수준의 MCP 서버를 따로 만들어, 이 도구와 에이전트가 주고받는 통신 형식이 실제로 동작하는지 확인했다. node mcp-client.js node mcp-hello.js server-hello를 실행했고, 초기화 응답, 도구 목록 조회, 도구 호출까지 모두 통과했다.

실제 도구는 돌리지 못했다. 설치를 하지 않은 상태라 npm run build로 빌드를 시도했다. 하지만 빌드 도구(GN·Ninja)가 없거나 의존성이 비어 있어 실패했다. 오프라인이라 npm 패키지도 받을 수 없고 로컬 빌드도 안 돼서, 실제 도구의 목록이나 스크린샷 같은 동작은 확인하지 못했다.

소스를 읽고 알게 된 것. 브라우저 프로파일은 MCP 경로에서 임시로 만들어졌다가 자동으로 정리된다고 한다. URL 허용·차단과 읽기 전용 모드도 설정할 수 있다. 원격 수집(사용량 통계, 성능 트레이스 URL)은 기본으로 켜져 있어 Google에 전송되며, 끄려면 별도 플래그나 환경 변수를 명시해야 한다고 한다.

이 맥에서 쓸 수 있나

이 맥은 Mac Studio, Apple M5 Max, 메모리 48GB, macOS 27.0.1이다. 이 도구에는 Node LTS, 현재 stable Chrome, npm이 필요하다. Node와 Chrome이 설치되어 있다면 조건은 맞출 수 있다.

메모리 48GB 중 로컬 AI 모델 서버가 약 34GB를 상시 쓰고 있다. 이 도구는 Node 기반이라 모델 서버와 충돌하지는 않는다. 다만 원격 수집이 기본으로 켜져 있다는 점은 알고 써야 한다. 끄는 플래그를 명시하면 이 맥에서도 무리 없이 쓸 수 있다.

이런 분께

  • 코딩 에이전트를 쓰면서 브라우저 실행 화면을 직접 점검하고 싶은 분
  • 성능, 네트워크, 콘솔 오류를 에이전트가 스스로 측정하고 반복 확인하게 하고 싶은 분
  • 읽기 전용 점검(JavaScript 실행 off)으로 안전하게 쓰고 싶은 분

안 맞는 분: 에이전트는 쓰지만 브라우저 제어나 성능 측정은 아직 필요 없는 분.

주의할 점

  • 원격 수집이 기본 on. 사용량 통계(도구 호출 성공률·레이턴시·환경 정보)와 성능 트레이스 URL을 Google에 보낸다고 한다. --no-usage-statistics나 --no-performance-crux를 꼭 명시해야 한다.
  • 로그인된 브라우저 프로필은 지정하지 마라. 브라우저 인스턴스 전체가 에이전트에 노출된다. 임시 프로필(isolated)로 쓰는 편이 안전하다.
  • evaluate_script는 페이지에서 JavaScript를 실행한다. 모델이 만든 스크립트가 그대로 돌기 때문에, 점검 용도라면 --no-javascript-evaluation으로 제한하길 권한다.
  • 지원 브라우저는 Google Chrome과 Chrome for Testing뿐이다. 다른 크로미움 계열은 공식 지원하지 않는다.
  • 최신 stable만 지원한다. Chrome 채널 업데이트에 따라 동작이 바뀔 수 있다.
