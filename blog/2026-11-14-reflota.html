reflota: 디스크에서 지운 파일 복구하는 오픈소스, 설치 없이 직접 돌려 봤다

2026년 11월 14일 · 읽는 데 4분
한 줄 요약하루 새 GitHub에서 생긴 파일 복구 도구 reflota를 받아, 설치도·인터넷도 없이 테스트만 돌려 본 기록. FAT 계열은 실제로 복구까지 확인했고, NTFS는 검증하지 못했으니 그 점만 유의하면 된다.

무엇인가

reflota는 NTFS, FAT32, FAT16, exFAT 디스크에서 파일을 복구하는 무료 오픈소스 도구다(라이선스 MIT, 확인 시 스타 11개). 2026년 11월 13일에 공개됐으니 이 글을 쓴 시점에는 만 하루 된 저장소다.

디스크를 직접 읽는 방식이다. NTFS에서는 MFT(마스터 파일 테이블, 디스크에 있는 파일 목록에 해당하는 구조)를 통째로 읽어 폴더 트리까지 다시 조립한다. FAT 계열에서는 폴더와 클러스터 체인(파일을 이루는 조각들의 연결 순서)을 따라간다.

지운 파일은 원래 폴더 위치에 다시 표시하고, 얼마나 남아 있는지(전체 intact 비율·부분·덮어쓰김)도 알려 준다. 형식을 몰라도 파일 자체의 특징으로 사진을 비롯한 30여 가지 포맷을 찾아내고, 파티션이 사라진 디스크에서는 파티션도 다시 찾아 준다.

README는 솔직하다. beta라고 적혀 있고, 최신 기능은 실제 디스크가 아닌 합성 테스트 이미지에서만 확인했다고 밝힌다. 읽기 전용이라 원본 디스크에는 절대 쓰지 않으며, 복사 대상은 반드시 다른 디스크여야 한다는 점도 명시돼 있다.

직접 해 본 것

저장소를 받아 설치 없이 살펴보고, 인터넷 없이 돌릴 수 있는 부분만 돌렸다. 설치는 하지 않았다.

구조부터 보면 핵심 엔진은 파이썬 파일 하나(약 5,600여 라인)이고, 서드파티 의존성은 0이다. 표준 라이브러리만으로 실행되니 "설치 없이 돌려 본다"는 말이 실제로 성립한다. 테스트 폴더는 합성 디스크 이미지를 기반으로 한다.

실행은 이렇게 했다.

python3 reflota.py --source disco.img --particiones
python3 reflota.py --source disco.img --ls / --borrados

FAT16 테스트 이미지(테스트 폴더에 있는 것)로 파티션 탐색, 디렉터리 나열, 삭제 파일 복원까지 모두 정상 동작했다. 테스트 전체도 통과했다.

못 한 것도 있다. 합성 NTFS 이미지를 직접 만들어 보려 했지만 만든 이미지가 엔진을 통과하지 못했고, 저장소에는 NTFS 테스트 이미지가 번들돼 있지 않았다(테스트는 FAT16 중심). 그래서 NTFS 경로는 검증하지 못했다. 이유는 셋이다. 첫째, 인터넷이 막혀 있어 실제 NTFS 이미지를 구할 수 없었다. 둘째, 저장소에 NTFS 테스트 이미지가 없다. 셋째, 실행 횟수 한도(60회)를 다 썼다.

GUI 버전은 실행하지 않았다. 윈도우용 .exe가 주된 배포 방식이라 이 맥에서는 돌릴 대상이 아니었다.

이 맥에서 쓸 수 있나

환경은 이렇다. Mac Studio, Apple M5 Max(arm64), 메모리 48GB, macOS 27.0.1(빌드 26A434), 디스크 여유 약 92GB. 로컬 AI 모델 서버가 메모리 약 34GB를 상시 사용 중이다.

요구 사항이 Python 3.8 이상과 서드파티 의존성 0뿐이라, 메모리 48GB·macOS 27.0.1 환경에서 돌리는 데는 걸림돌이 없다. 테스트도 이 환경에서 돌렸다.

다만 현실적인 벽이 하나 있다. 이 도구가 읽는 포맷은 NTFS·FAT 계열뿐이라 Apple의 파일시스템인 APFS 디스크는 그대로 읽지 못한다(APFS·HFS+·ext4·BitLocker는 미지원). 그러니 외장 APFS 디스크의 삭제 파일을 다루려면 먼저 그 디스크의 NTFS/FAT 이미지를 따로 만들어 두고, 그 이미지를 대상으로 써야 한다. APFS 디스크를 바로 분석하는 건 안 된다.

이런 분께

이런 분께 맞아요:

  • NTFS·FAT 외장 디스크·펜드라이브에서 파일을 지웠거나, 디스크가 "포맷 안 된 드라이브"로 뜨는 분
  • 지운 파일이 얼마나 남아 있는지 확인하고, 원래 폴더 위치에서 다시 찾고 싶은 분
  • 광고나 라이선스 걱정 없는 윈도우용 복구 도구를 찾는 분. 읽기 전용·MIT·의존성 0이다

이런 분께 안 맞아요:

  • 외장 디스크가 APFS·HFS+인 분(지원 포맷이 아니라서 바로 쓰려면 먼저 이미지로 만들어야 한다)
  • bitlocker 등으로 암호화한 디스크를 다루는 분(미지원)
  • beta 도구의 한계가 부담스러운 분. README도 "각 디스크는 다르고, 중요한 건 먼저 복사해 두고 써라"고 권고한다

주의할 점

beta라는 점을 가장 먼저 기억해 둘 것. README의 표현을 빌리면 "각 디스크는 다르고, 최근 기능은 실제 디스크가 아닌 테스트 이미지만으로 검증됐다"이다. 이 글에서 확인한 것도 FAT 계열만 실측이었고, NTFS 동작은 확인하지 못했다.

원본 디스크는 계속 쓰지 마라. 삭제된 파일의 공간에 새 데이터가 덮어쓰이기 시작하면 복구할 수 없게 된다. 복사는 반드시 다른 디스크로 한다. 도구는 읽기 전용이라 원본을 건드리지 않는다.

디스크에서 소리가 나거나 오류가 반복된다면 물리적 고장이니 이 도구의 영역이 아니다. 전문 복구 업체에 맡기는 편이 낫다.

윈도우에서 .exe를 쓰면 프로그램에 서명이 없어 Windows Defender 경고가 뜨고, 일부 백신은 디스크를 직접 읽는 동작 자체를 의심할 수 있다. 오픈소스라 직접 컴파일할 수도 있고, 릴리스마다 SHA256 해시가 함께 공개된다.
