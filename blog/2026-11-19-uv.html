uv 0.13.9 소스를 받아 인터넷 없이 직접 돌려 본 기록

2026년 11월 19일 · 읽는 데 4분
한 줄 요약uv는 Rust로 만든 Python 패키지·프로젝트 관리자다. 소스를 받아서 설치도, 인터넷 연결도 없이 살펴보고 돌려 봤다. 확인한 건 의존성 없는 스크립트 실행과 Python 버전 관리까지다. 의존성이 있는 작업은 이 환경에서 해 보지 못했다.

무엇인가

uv는 pip, pip-tools, pipx, poetry, pyenv, twine, virtualenv처럼 Python 쪽에서 따로 쓰던 도구들을 하나로 묶은 관리 도구다. 의존성 해석과 고정, 프로젝트 관리, 스크립트 실행, Python 버전 관리, 도구 설치를 지원하고 pip 호환 인터페이스도 있다. README에는 Rust로 작성해서 10~100배 빠르다고 적혀 있다. GitHub 별은 92,181개다.

라이선스는 Apache-2.0과 MIT 이중 라이선스라 상업용으로 써도 된다. 개발은 Ruff를 만든 Astral이 맡고 있다.

직접 해 본 것

uv 0.13.9 소스는 로컬에 받아 두기만 했고, 명령은 이 맥에 원래 깔려 있던 uv 0.12.23으로 돌렸다. 인터넷은 끊었고 새로 설치한 것도 없다.

성공한 것:

  • uv python list: 이 맥에 있는 Python 3.8~3.15를 보여 줬다. 인터넷 없이 캐시와 로컬 탐색만으로 됐다.
  • uv run --no-project --offline demo.py: uv가 관리하는 CPython 3.14.7로 스크립트를 실행했다. 다운로드 없이 0.03초 걸렸다.
  • uv venv --python 3.14: 가상 환경을 0.1초 만에 만들었다.

실패한 것(예상한 실패):

  • pyyaml 의존성이 있는 스크립트를 --offline으로 실행했더니 "pyyaml was not found in the cache"라며 실패했다. 이 맥의 캐시에 pyyaml이 없고 인터넷도 없으니 의존성을 풀 방법이 없다.
  • uv 0.13.9 소스를 uv sync --offline --frozen으로 동기화하는 것도 실패했다. 이유는 두 가지다. (1) 시스템에 깔린 uv 0.12.23은 0.13에서 새로 생긴 preview 필드를 모른다. (2) .python-versions는 3.14.10을 요구하는데 이 맥에는 3.14.7밖에 없어서 새로 내려받아야 한다.
  • 작은 프로젝트를 만들어 uv sync --offline을 해 봤지만 역시 실패했다. 캐시에 패키지가 없으니 의존성 없는 환경까지만 만들 수 있었다.

확인한 것: uv.lock 파일 구조를 열어 봤다. 패키지 97개 중 83개가 PyPI에서 왔고, 패키지마다 sha256 해시와 업로드 시각이 적혀 있다. 시점을 고정하는 필드도 있다.

정리하면, 오프라인에서 문제없이 되는 건 의존성 없는 스크립트 실행과 Python 버전 관리다. 의존성 해석과 설치에는 캐시나 인터넷이 필요해서 이번 환경에서는 거기까지 확인하지 못했다.

이 맥에서 쓸 수 있나

이 맥은 Mac Studio다. Apple M5 Max(arm64), 메모리 48GB, macOS 27.0.1(빌드 26A434)이고 디스크는 약 132GB 남아 있다. 로컬 AI 모델 서버가 메모리를 늘 34GB쯤 쓰고 있다.

uv는 Python 프로세스 기준으로 몇 MB 정도라 가볍다(부하는 따로 재지 않았다). M5 Max arm64는 uv가 공식 지원하는 macOS 플랫폼이다. 다만 앞에서 말한 AI 모델 서버가 같이 돌고 있다는 점은 감안해야 한다.

이 맥에는 Homebrew로 깐 uv 0.12.23이 이미 있고, uv가 관리하는 Python 3.12.15 / 3.13.16 / 3.14.7도 있다. 그래서 따로 설치하지 않고 바로 스크립트를 돌리거나 버전을 고를 수 있다.

이런 분께

맞는 분:

  • Python 스크립트를 자주 돌리는데 가상 환경 관리가 귀찮은 분
  • pip이 느려서 다른 도구를 찾는 분
  • Python 버전을 자주 바꿔 쓰는 분
  • 오프라인에서도 의존성 없는 스크립트는 돌리고 싶은 분

안 맞는 분:

  • 의존성 있는 프로젝트 환경을 오프라인에서 그대로 재현해야 하는 분(캐시나 인터넷이 있어야 한다)
  • 주로 Node.js 기반으로 작업하는 분
  • uv 0.13.x의 preview 기능은 쓰고 싶은데 버전은 0.12.23에 묶어 두려는 분

주의할 점

  • uv는 마이너 버전이 오를 때마다 preview 기능이 추가되기 때문에 uv self update를 하면 동작이 달라질 수 있다. 버전을 고정해 두고 쓰는 편이 안전하다.
  • 의존성 있는 스크립트를 돌리려면 PyPI에 접속할 수 있어야 한다. 오프라인에서는 실행되지 않는다.
  • 0.13.x 소스의 개발 환경은 Python 패치 버전까지 정해 두고 있다. 이 맥에서 uv가 관리하는 버전과 맞지 않으면 다시 내려받아야 한다.
  • 의존성 해석·설치 속도(10~100배)는 인터넷이나 캐시가 있는 환경에서 확인해야 한다. 이번에는 검증하지 못했으니 README에 적힌 주장 정도로만 보면 된다.
