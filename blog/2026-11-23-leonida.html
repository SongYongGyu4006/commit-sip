GTA VI, Xbox 패키지 직접 맥에서 살펴본 기록

2026년 11월 23일 · 읽는 데 6분
한 줄 요약GTA VI의 Xbox 전용 버전을 PC에서 네이티브로 돌리려는 오픈소스 재컴파일 프로젝트 Leonida를 받아서, 설치하지 않고 인터넷도 끊은 채로 살펴보고 실행해 봤다.

무엇인가

Leonida는 GTA VI의 Xbox Series 패키지(1.0.2.1)를 자기 PC에서, 자기가 가진 게임 복사본으로 실행하게 해 주는 프로젝트다. Xbox CPU는 PC와 같은 x86-64 아키텍처여서 게임 코드는 그대로 네이티브로 불러오고, 콘솔 전용 시스템 소프트웨어는 새로 구현한 코드로 대신한다. 게임의 GPU 프로그램은 Xbox 전용 RDNA2(AMD 그래픽 칩셋 아키텍처 이름) 형식으로 들어 있다. 이걸 LLVM(컴파일러 프로젝트)으로 분해한 다음 Vulkan용 SPIR-V(그래픽 명령어 중간 표현)로 바꾼다. 모델, 텍스처, 오디오는 모두 사용자의 패키지 파일에서 읽어 온다.

가장 중요한 점은 저장소에 게임 데이터도, 키도, 실행 파일도 없다는 것이다. 이 프로젝트는 "게임 없이 모든 것을 준비했다"는 상태지만, 게임은 아직 부팅조차 안 되는 초기 단계다. GitHub 정보(확인 시각: 2026-11-23 02:33 KST): 12,363 stars, 977 forks, 2026-11-20 생성(약 3일), GPL-3.0, 주 언어 Python.

직접 해 본 것

테스트 환경은 Mac Studio, Apple M5 Max, macOS 27.0.1이고, 시스템 Python 3.9.6과 Homebrew Python 3.14.8을 썼다. 인터넷은 끊어 둔 상태였다. 저장소는 내려받았지만 설치는 하지 않았고, 게임 파일이나 GPU 없이 돌아가는 부분만 실행해 봤다.

  1. 시스템 Python 3.9에서는 도구가 실행되지 않는다. python3 -I make_game.py --help를 실행하니 396행에서 TypeError: unsupported operand type(s) for |: 'type' and 'NoneType' 오류가 났다. 코드는 Python 3.10+ 문법을 쓰는데 이 Mac의 시스템 Python이 3.9라서 import 단계에서 바로 멈춘다.
  1. Python 3.14에서는 잘 돈다. 같은 명령을 Homebrew Python 3.14로 실행하니 오류 없이 전체 옵션 목록이 나왔다.
/opt/homebrew/bin/python3.14 -I make_game.py --help
  1. 게임 파일이 없어도 도는 회귀 테스트는 통과했다. GPU, LLVM, 게임 파일 없이 돌릴 수 있는 테스트 스위트가 203개 파일에 들어 있어서 실행해 봤다.
/opt/homebrew/bin/python3.14 -I -m unittest discover -s tests/semantic

결과는 Ran 2567 tests in 86.4s OK (skipped=3). 2,567개 가운데 3개는 환경 문제로 건너뛰었고, 나머지는 모두 통과했다.

  1. 로컬 뷰어 서버의 보안 방어도 확인했다. 저장소에 표준 라이브러리만으로 돌아가는 맵 뷰어(127.0.0.1 전용 로컬 서버)가 있어서 띄워 봤다.
/opt/homebrew/bin/python3.14 -I viewer/serve.py --port 0

정상 Host 헤더로 /에 GET을 보내면 200(18,565 bytes)이 돌아왔다. 악성 Host 헤더(evil.example, DNS 리바인딩 시도)로 보내면 403, 경로 탐색(/world/..%2Fmake_game.py)은 404였다. 방어 로직은 실제로 작동했다.

  1. 게임 복사본 검색. python3.14 -I make_game.py --find를 실행하니 0 found가 나왔다. 이 Mac에는 GTA VI 패키지가 없어서 check 다음 단계는 확인하지 못했다.

못 한 것: C++로 짠 런타임과 에셋 추출 도구는 빌드하지 못했다. 저장소의 서브모듈(제3자 코드)이 비어 있었는데 인터넷이 끊겨 있어 받아 올 수 없었고, CMake, Windows SDK, Vulkan SDK도 없었다. 이 프로젝트가 전제로 하는 Windows, AMD GPU, 게임 패키지가 없으니 실제 GPU 실행과 게임 부팅도 해 보지 않았다.

이 맥에서 쓸 수 있나

못 쓴다. 이 프로젝트에 필요한 건 Windows 10/11 x64, 작업 공간 350 GB, Windows SDK 10.0.26100 이상, .NET 8 SDK, Vulkan SDK, AMDGPU 대상 LLVM 21+, ffmpeg, 그리고 1.0.2.1 버전 GTA VI Xbox 패키지다. 이 Mac은 Apple M5 Max, 메모리 48GB, macOS 27.0.1, 디스크 여유 약 138GB이고 Windows도, AMD GPU도, 게임 패키지도 없다. 디스크 여유 138GB는 요구량 350GB에 한참 못 미친다. 게다가 로컬 AI 모델 서버가 메모리를 약 34GB씩 늘 쓰고 있어서 설치를 시도할 여유도 없다. 정리하면 이건 "내 PC에 깔아 쓰는 도구"가 아니다. Windows와 AMD GPU, 직접 산 GTA VI를 모두 갖춰야 겨우 시작할 수 있는 작업이다.

이런 분께

맞아요 — GTA 시리즈나 게임 포팅, 재컴파일 기술에 관심이 있고, Windows PC(AMD GPU)와 게임을 직접 갖고 있는 분. "게임 없이도 전부 준비하는" 단계의 엔지니어링 문서가 잘 정리돼 있어서 코드만 읽어도 배울 게 많다.

안 맞아요 — 이 글을 보고 "맥에서 GTA VI 돌리기"를 기대한 분(안 된다). 게임을 사지 않은 분, Windows 머신이 없는 분, "설치하고 바로 실행"을 원하는 분.

주의할 점

라이선스는 두 가지를 따로 봐야 한다. Leonida 코드는 GPL-3.0이지만, 이건 코드에 붙은 라이선스일 뿐 GTA VI 자체의 저작권과는 별개다. 상업 게임을 PC에서 실행하거나 재배포하는 행위는 게임사 권리를 건드릴 수 있다. "GPL이라 문제없다"로 끝낼 일이 아니다.

재배포하면 GPL 조건을 따라야 한다. 코드를 고쳐서 재배포하는 순간 전체가 GPL 조건에 묶인다. 비상업 블로그 기록(문서, 스크린샷, 링크)은 괜찮지만, 코드 자체를 재배포하면 GPL이 적용된다.

에셋 내보내기("asset export")가 잘 된다는 주장은 따로 검증하지 못했다. 에셋 추출 도구가 쓰는 제3자 코드(서브모듈)가 이 환경에서 비어 있어서 직접 확인할 수 없었다.

아직 초기 단계다. 부팅, 스토리 모드, 플레이 모두 아직 안 된다. 지금 이 프로젝트에 기대를 걸기엔 이르다.
