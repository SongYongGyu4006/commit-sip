로컬 Mac 코딩 에이전트 localcode, 설치 없이 직접 살펴본 기록

2026년 11월 23일 · 읽는 데 4분
한 줄 요약Mac에서 소형 AI 모델로 코딩 에이전트를 돌리는 오픈소스 localcode를 받아 봤습니다. 패키지 설치나 모델 다운로드는 하지 않았고, 코드를 읽고 돌려볼 수 있는 부분만 골라 직접 실행했습니다.

무엇인가

localcode는 Apple Silicon 맥에 올린 로컬 모델로 "에이전틱 코딩"을 하는 도구입니다. 에이전틱 코딩은 AI가 파일을 읽고 고치고, 테스트와 명령어를 실행하는 일을 스스로 반복하는 방식입니다. localcode는 프로젝트 안의 파일을 읽고 편집하며 테스트·빌드·git·shell 명령도 알아서 실행합니다. 사용자에게 묻는 건 프로젝트 밖의 것을 건드리기 전뿐입니다. 코드는 이름·내용·구조로 검색할 수 있고, 앱 초안을 만든 뒤 실행해서 응답하는지까지 확인합니다.

설치는 uv pip install localcode 한 줄이면 되고, 프로젝트 폴더에서 localcode만 입력하면 됩니다. localcode api를 실행하면 OpenAI 호환 API도 열립니다. 요구 사양은 Apple Silicon 맥, macOS 13 이상, 통합 메모리 16GB 이상, Python 3.10 이상입니다. 모델은 Hugging Face에서 받아오며 12종·169개 퀀트 옵션이 있습니다. 퀀트는 같은 모델을 더 작은 파일로 압축하는 방식인데, 숫자가 작을수록 더 작고 가벼운 버전입니다.

직접 해 본 것

저희 환경은 인터넷이 막혀 있어 패키지 설치도, 모델 다운로드도 할 수 없었습니다. 그래서 CLI 화면과 모델 로딩까지 포함해 제품 전체를 처음부터 끝까지 돌려 보지는 못했습니다. 대신 외부 의존성 없이 표준 라이브러리만으로 도는 순수 로직 코드를 골라 이 맥에서 실제로 실행했습니다.

  1. 모델이 이 Mac에 들어맞나 확인하는 부분 — 코드가 이 맥의 실제 메모리 48GB를 직접 읽어 왔고, 27B 4bit 모델(파일 6.2GB)은 16GB부터 128GB까지 모든 맥에서 "들어맞음"으로 판정됐습니다. 저희 맥의 GPU 가용 예산은 37.44GB로 나왔고, 16GB 파일은 들어맞았지만 가장 큰 퀀트(54.7GB)는 "너무 큼"이었습니다.
  1. 메모리 보호 로직 — 시스템 값을 실제로 읽어 보니 이 맥은 지금 메모리 경고 상태(warn)였습니다. 이 상태에서는 치명적인 커널 메모리 한계를 걸지 않고, 부드러운 종료 감시만 켜는 것을 확인했습니다.
  1. 비밀 정보 치환 — 지어낸 가짜 토큰(실제 비밀은 전혀 쓰지 않았습니다)을 코드에 섞어 넣어 봤습니다. Anthropic·GitHub·Hugging Face 토큰과 private key 블록은 [redacted:...]으로 바뀌었고, 일반 코드와 git SHA는 그대로 남았습니다.
  1. 릴리스 품질 게이트 — 합성 로그 두 개를 만들어 A/B 테스트를 했습니다. 성능이 90 tok/s에서 45 tok/s로 반토막 나고 전부 실패한 버전은 "BLOCKED"로 막혔고, 변화가 없는 버전은 "OK"로 통과했습니다. 규칙이 실제로 동작했습니다.

이 맥에서 쓸 수 있나

저희 맥은 Mac Studio(Apple M5 Max), 통합 메모리 48GB, macOS 27.0.1, 디스크 여유 약 134GB입니다. localcode의 요구 사양(Apple Silicon, macOS 13 이상, 통합 메모리 16GB 이상, Python 3.10 이상)과 맞춰 보면 OS·메모리·디스크 모두 여유 있게 넘습니다.

모델도 문제없습니다. 가장 작은 27B 4bit가 6.2GB라 디스크 여유 134GB로도, 통합 메모리 48GB로도 충분합니다. 다만 현실적인 제약이 하나 있습니다. 이 맥에서는 로컬 AI 모델 서버가 이미 상시 약 34GB를 쓰고 있습니다. 여기에 localcode의 27B 모델까지 띄우면 두 서버가 GPU 가용 예산(37.44GB)을 두고 다투다 강제 종료될 위험이 있습니다. 요구 사양은 넘지만 이 48GB 맥에서 모델 서버 두 개를 동시에 돌리는 건 위험하니, 한쪽은 꺼야 합니다.

이런 분께

맞아요 — 맥에서 인터넷 없이 로컬 모델로 코딩해 보고 싶은 분, API 비용이나 데이터 유출 걱정 없이 코딩 에이전트를 쓰고 싶은 분, 메모리 16GB 이상인 맥을 가진 개발자·학생.

안 맞아요 — Windows·Linux 사용자(맥 전용), 메모리 16GB 미만인 맥 사용자, 이미 무거운 모델 서버를 돌리고 있어 같은 메모리에 27B 모델을 하나 더 올릴 여유가 없는 분.

주의할 점

  • 아직 정식 릴리스 전인 Alpha 단계이고, 현재 버전은 rc(공식 출시 전 후보)입니다.
  • 모델 서버 포크 같은 제3자 코드도 함께 들어 있습니다. 다시 배포할 때는 각 코드의 라이선스 고지를 그대로 보존해야 합니다.
  • 앞서 말했듯이 이미 큰 모델을 돌리는 환경에서는 실제로 메모리 경쟁이 생길 수 있습니다.
  • 설치와 모델 다운로드가 막힌 환경이어서 제품 전체 실행은 확인하지 못했습니다. 실제로 쓰기 전에 각자 환경에서 확인해 보시길 권합니다.
