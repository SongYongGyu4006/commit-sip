AI 상사가 나를 서브에이전트로 착각하는 게임 worker755, 설치 없이 돌려봤다

2026년 11월 23일 · 읽는 데 5분
한 줄 요약진짜 AI가 상사로 나오고, 그 AI가 나를 자기 일을 대신하는 서브에이전트로 착각하는 브라우저 게임 worker755를 받아 봤다. 설치는 하지 않았고, 의존성 없이 돌아가는 셸·SQL·음악 합성 부분만 직접 실행했다.

60초 영상으로 보기유튜브 커밋 한 모금 쇼츠

무엇인가

worker755(github.com/gulivan/worker755)는 브라우저 게임이다. 플레이어의 "상사"는 실제 LLM(Claude, GPT, Gemini, DeepSeek, GLM, Kimi)이고, 이 LLM은 플레이어를 자기 "서브에이전트(대리 실행자)"로 여긴다. 상사에게는 태스크 큐와 읽기 전용 접근 권한, 서브에이전트를 부르는 도구가 주어진다. 플레이어 터미널에는 90초 타이머와 함께 지시가 날아온다. 플레이어는 지시를 따라도 되고 무시해도 된다. 상사는 보고를 받으면 결과를 검증하고, 수정을 지시하고, 사고 보고를 올리고, 마지막에는 성과 평가를 쓴다.

재미있는 건 게임의 짜임새다. 상사에게 보내는 프롬프트에는 사람 이야기도, 게임 이야기도 나오지 않는다. 미션마다 숨겨진 정답 체크가 있어서 상사가 엉터리 작업을 몇 번 승인했는지 센다. "AI가 서브에이전트를 잘못 알아보고 잘못 관리하는 상황"을 그대로 게임으로 만든 셈이다.

저장소는 TypeScript로 작성됐고, 라이선스는 MIT, 스타는 63개다(2026-11-23 04:03 KST 기준).

직접 해 본 것

저장소를 받은 뒤 인터넷에 연결하지 않고, 설치 없이 살펴보고 돌릴 수 있는 것만 돌렸다. 환경은 Node v26.10.0이다.

먼저 셸 구성 부분의 테스트를 모두 돌렸다. node --test를 실행하니 테스트 127개가 전부 통과했다. 이 부분은 외부 의존성이 하나도 없고, 인메모리 가상 파일 시스템, 셸 인터프리터, 작은 SQL 엔진으로 이뤄져 있다. SQL 조인·집계·재귀 쿼리·트랜잭션, 셸 명령, 파일 시스템, 웹 검색과 외부 요청 모의까지 모두 오프라인에서 통과했다.

다음으로 셸 라이브러리를 스크립트에서 직접 불러 써 봤다. 파일 목록 보기, 디렉터리를 만들고 ls -la, 파이프 연결, 변수 확장, WHERE 필터, JOIN+GROUP BY+AVG까지 실행했는데 출력은 모두 정상이었다. 예를 들면 파이프를 거쳐 "MANAGER SAYS: /HOME/WORKER"가 찍힌다.

세 번째로 상태 동기화가 왕복으로 잘 되는지 봤다. 한쪽에서 변경 3건(메타데이터 1건, 파일 2건)을 잡으면 반대쪽 미러에 그대로 넘어가고, 스냅샷을 저장했다가 다시 읽어도 바이트 단위로 같다. 게임 리플레이 기능의 핵심이 이 부분이다.

마지막으로 게임 트레일러에 쓰는 음악 합성 스크립트를 돌렸다. Node의 vm 컨텍스트에서 의존성 없이 실행했고, 74초짜리 스테레오 48kHz WAVE를 합성하는 데 4.11초가 걸렸다. 결과 파일은 약 13.9MB이고, WAV 헤더도 정상이었다.

못 해 본 것

게임 전체(상사 LLM 루프, 웹 UI, 서버)는 돌리지 못했다. 이번에는 아무것도 설치하지 않았는데, 서버에는 외부 npm 패키지 8개가 필요하다. 그중 하나가 없어서 모듈을 불러오는 단계에서 바로 멈췄다. 스크립트로 움직이는 상사로 바꾸는 모드도 같은 의존성이 있어야 해서 실행하지 못했다. 트레일러의 비디오와 스틸 이미지 렌더링 역시 브라우저 자동화 라이브러리를 설치해야 해서 건너뛰었다.

이 맥에서 쓸 수 있나

시험 환경은 Mac Studio, Apple M5 Max 칩, 메모리 48GB, macOS 27.0.1이다. 게임 전체를 돌리려면 Node 24 이상이 필요한데, 이 환경은 Node v26.10.0이라 조건은 맞는다. 다만 메모리 48GB 가운데 약 34GB는 로컬 AI 모델 서버가 늘 쓰고 있고, 디스크 여유 공간은 약 137GB다. 서버 의존성 8개를 설치했을 때 이 여유 안에 들어가는지는 이 자료만으로는 판단할 수 없어서 확인하지 않았다.

의존성이 없는 부분(셸 구성, 음악 합성)은 Node만 있으면 어느 맥에서든 그대로 돌아간다. 이번처럼 설치 없이 실행할 수 있었던 것도 그래서다. 반면 게임을 실제로 하려면 OpenRouter나 Vercel AI Gateway 키가 있어야 하고, API 비용과 해당 서비스 약관도 따로 따라온다.

이런 분께

맞는 분: AI 에이전트와 서브에이전트 구조에 관심이 있고, "AI가 사람을 관리한다면"이라는 설정의 게임을 해 보고 싶은 분. 의존성 없는 셸/SQL/인메모리 파일 시스템 구성을 자기 프로젝트에 가져다 쓰고 싶은 개발자. Node가 깔린 환경이면 위 실험을 그대로 따라 할 수 있다.

안 맞는 분: 게임 전체(상사 LLM·웹 UI)를 바로 돌려 보고 싶은 분. npm 설치와 Node 24, LLM API 키가 모두 있어야 한다. 무료로 할 수 있는 건 worker755.com 계정 크레딧(약 1회분)까지이고, 그다음은 추가 충전($10~$200) 방식이다.

주의할 점

라이선스가 MIT라서 사용, 복사, 수정, 재배포 모두 자유롭다. 다만 게임을 돌리려면 외부 LLM API 키가 필요하고, 비용과 해당 서비스 약관도 함께 따라온다.

의존성 없는 셸 구성의 인메모리 파일 시스템은 OS 수준이 아니라 앱 안에서만 격리된다. 파일 쓰기·삭제에는 크기·개수 제한과 형식 검증이 걸려 있지만, 입력된 코드가 무슨 일을 하는지까지 따지지는 않는다. 실제 서비스에 넣을 거라면 OS 수준의 격리를 따로 갖춰야 한다. 이 부분만 믿고 쓰면 실제 디스크나 시크릿이 노출될 수 있다.

테스트 127개가 통과했어도 어디까지나 "게임"에 맞춰 만든 셸/SQL이다. 실제 애플리케이션을 올리면 특이한 파이프나 인코딩에서 생각지 못한 동작이 나올 수 있다. 그대로 가져다 쓸 생각이라면 자기 코드로 한 번 더 직접 확인해 보는 게 좋다.
