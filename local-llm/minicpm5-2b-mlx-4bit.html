자주 묻는 질문

맥에서 MiniCPM5-2B-mlx-4Bit의 실제 속도는?

측정 결과 짧은 입력(512토큰) 시 답 쓰는 속도는 238토큰/초, 긴 입력(4096토큰) 시 242.5토큰/초입니다. 읽기 속도는 각각 7572토큰/초, 10791토큰/초로 매우 빠릅니다.

이 모델의 한국어 능력과 코딩 성능은?

한국어 답변 점수는 5점 만점에 2점으로, 문장이 부자연스럽고 정보 전달력이 떨어집니다. 한국어 객관식(KMMLU) 정답률은 17/50이며, 파이썬 코딩은 10문제 중 7/10이 통과했습니다.

맥 스튜디오 M5 Max에서 메모리는 얼마나 쓰나요?

가중치 용량은 1.4GB이며, 실제 측정 시 최대 메모리 사용량은 2.4GB였습니다. 맥 로컬 llm 디시 등에서 언급된 사양 대비 낮은 메모리 사용이 특징입니다.

긴 문서 처리나 도구 호출은 가능한가요?

약 16K토큰과 32K토큰 길이의 글 속 문장 찾기는 각각 2.4초, 6.8초 만에 완료했습니다. 하지만 도구 호출 정확도는 10문항 중 1/10에 불과합니다.

측정 방법

맥 스튜디오 M5 Max, 통합 메모리 48GB에서 mlx-lm 0.32.0 (MLX 0.32.3)로 측정했습니다. 입력 512토큰·4096토큰 뒤 128토큰을 생성하는 시험을 여러 번 반복한 평균이고, 한국어 답변은 온도 0으로 한 번 생성한 원문 그대로입니다(생각 과정은 떼고 답만). 추가 시험(있는 경우)은 모두 코드로 채점합니다: 한국어 객관식은 KMMLU(HAERAE-HUB, CC BY-ND 4.0) 10개 분야 50문항, 도구 호출·파이썬 코딩·형식 지시는 각 10문항(코딩은 인터넷이 막힌 환경에서 숨겨진 테스트 실행), 긴 글 찾기는 약 1만6천·3만2천 토큰 글 속에 넣은 문장을 찾는지, 튀는 공은 한 번에 만든 HTML 이 실제로 움직이는지입니다. 생각 기능은 끄고 온도 0으로 실행했습니다. 가중치는 Hugging Face의 mlx-community/MiniCPM5-2B-mlx-4Bit를 썼습니다.
