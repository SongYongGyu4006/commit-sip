자주 묻는 질문

Qwen3.6 35B A3B를 맥에서 돌리려면 어떤 사양이 필요한가요?

실측은 맥 스튜디오 M5 Max(통합 메모리 48GB)에서 진행되었습니다. 가중치 용량이 22.2GB이므로, 모델 로드와 추론을 위한 충분한 통합 메모리가 필요합니다. mlx-lm 0.32.0을 사용해 측정했습니다.

답 쓰는 속도가 얼마나 빠른가요?

짧은 입력(512토큰) 기준 답 쓰는 속도는 초당 125.4토큰, 긴 입력(4096토큰) 기준으로는 초당 120.3토큰으로 측정되었습니다. 이는 사람이 읽는 속도(초당 약 5토큰)보다 훨씬 빠릅니다.

한국어 성능은 어떤가요?

한국어 답변 점수는 5점 만점 중 5점을 받았으며, 외국어 섞임이 없었습니다. 평가에서는 '요청된 형식과 내용을 정확히 전달하며 문장이 자연스럽다'는 평을 받았습니다.

코딩과 도구 호출 능력은 어떤가요?

파이썬 코딩 10문제 모두 테스트를 통과(10/10)했으며, 도구 호출 정확도는 10문항 중 9문항(9/10)이 정확했습니다. 형식 지시 따르기도 10문항 중 10문항(10/10)으로 높았습니다.

측정 방법

맥 스튜디오 M5 Max, 통합 메모리 48GB에서 mlx-lm 0.32.0 (MLX 0.32.3)로 측정했습니다. 입력 512토큰·4096토큰 뒤 128토큰을 생성하는 시험을 여러 번 반복한 평균이고, 한국어 답변은 온도 0으로 한 번 생성한 원문 그대로입니다(생각 과정은 떼고 답만). 추가 시험(있는 경우)은 모두 코드로 채점합니다: 한국어 객관식은 KMMLU(HAERAE-HUB, CC BY-ND 4.0) 10개 분야 50문항, 도구 호출·파이썬 코딩·형식 지시는 각 10문항(코딩은 인터넷이 막힌 환경에서 숨겨진 테스트 실행), 긴 글 찾기는 약 1만6천·3만2천 토큰 글 속에 넣은 문장을 찾는지, 튀는 공은 한 번에 만든 HTML 이 실제로 움직이는지입니다. 생각 기능은 끄고 온도 0으로 실행했습니다. 가중치는 Hugging Face의 mlx-community/Qwen3.6-35B-A3B-OptiQ-4bit를 썼습니다.
