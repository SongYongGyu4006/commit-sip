맥 스튜디오 M5 Max에서 Spark-X2.5-4B 로컬 llm 실측 결과

맥 스튜디오 M5 Max에서 가벼운 로컬 llm을 빠르게 구동하고 싶은 사용자에게 적합하지만, 한국어 사실성 검증은 필수입니다.

2026년 10월 23일, 맥 스튜디오 M5 Max(48GB) 환경에서 mlx-lm 0.32.0을 사용해 Spark-X2.5-4B-OptiQ-4bit를 측정했습니다. 짧은 입력 기준 답 쓰는 속도는 초당 142.9토큰으로, 사람이 읽는 속도(초당 약 5토큰)보다 훨씬 빠릅니다. 다만 한국어 객관식(KMMLU) 정답률이 16/50으로 낮아, 중요한 정보 확인 시 주의가 필요합니다.

자주 묻는 질문

맥 스튜디오 M5 Max에서 이 모델의 답 쓰는 속도는 얼마나 되나요?

짧은 입력(512토큰) 기준 초당 142.9토큰, 긴 입력(4096토큰) 기준 초당 137.9토큰으로 측정되었습니다.

맥북 llm 설치 시 필요한 메모리는 얼마나 되나요?

측정 결과 최대 메모리 사용량은 4.3GB로 확인되었습니다. 가중치 용량은 3.1GB입니다.

한국어 성능은 어떤가요?

5점 만점 기준 3점을 받았으며, 외국어 섞임은 없었지만 로컬 모델 원리 오해와 모순된 보안 조언이 있어 사실성이 떨어집니다.

코딩과 도구 호출 능력은 어느 정도인가요?

파이썬 코딩은 10문제 중 7문제, 도구 호출은 10문항 중 6문항을 정확히 수행했습니다.

측정 방법

맥 스튜디오 M5 Max, 통합 메모리 48GB에서 mlx-lm 0.32.0 (MLX 0.32.3)로 측정했습니다. 입력 512토큰·4096토큰 뒤 128토큰을 생성하는 시험을 여러 번 반복한 평균이고, 한국어 답변은 온도 0으로 한 번 생성한 원문 그대로입니다(생각 과정은 떼고 답만). 추가 시험(있는 경우)은 모두 코드로 채점합니다: 한국어 객관식은 KMMLU(HAERAE-HUB, CC BY-ND 4.0) 10개 분야 50문항, 도구 호출·파이썬 코딩·형식 지시는 각 10문항(코딩은 인터넷이 막힌 환경에서 숨겨진 테스트 실행), 긴 글 찾기는 약 1만6천·3만2천 토큰 글 속에 넣은 문장을 찾는지, 튀는 공은 한 번에 만든 HTML 이 실제로 움직이는지입니다. 생각 기능은 끄고 온도 0으로 실행했습니다. 가중치는 Hugging Face의 mlx-community/Spark-X2.5-4B-OptiQ-4bit를 썼습니다.
