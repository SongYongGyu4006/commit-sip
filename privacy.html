1. 이 방침이 다루는 것

이 방침은 웹사이트 '커밋 한 모금'과, 운영자가 자기 유튜브 채널에 영상을 올리기 위해 쓰는 업로드 도구(Google OAuth 앱 이름: hermes-mac)에 적용됩니다.

2. 수집하는 개인정보

이 웹사이트는 방문자의 개인정보를 수집하지 않습니다. 회원가입·로그인·댓글·쿠키 기반 추적·광고 추적이 없습니다. 웹사이트를 제공하는 GitHub Pages가 서비스 운영을 위해 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다.

3. 유튜브 업로드 도구가 쓰는 Google 데이터

  • 업로드 도구는 운영자 본인의 Google 계정으로만 로그인해 쓰며, 다른 사람의 계정에는 접근하지 않습니다.
  • 요청하는 권한: YouTube 영상 업로드(youtube.upload), 운영자 채널의 영상 공개 상태 변경(youtube).
  • 사용 목적: 운영자가 만든 쇼츠를 운영자 채널에 '비공개'로 올리고, 운영자가 승인한 경우에만 '공개'로 바꾸는 것.
  • 저장: 로그인 결과로 받은 인증 토큰은 운영자 개인 컴퓨터에만 저장되며(본인만 읽을 수 있는 파일), 외부 서버로 보내거나 다른 사람과 공유하지 않습니다.
  • Google 사용자 데이터를 판매하거나 광고에 쓰거나, 인공지능 모델 학습에 쓰지 않습니다.
  • 권한은 언제든 Google 계정의 서드파티 연결 관리에서 해제할 수 있습니다.

업로드 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)과 YouTube 서비스 약관을 따릅니다.

4. 보관과 삭제

운영자가 업로드 도구 사용을 멈추면 컴퓨터에 저장된 토큰을 삭제합니다. 방문자에 관해 보관하는 정보는 없습니다.
